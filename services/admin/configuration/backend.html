Admin Backend configuration

Admin Backend (epam/ai-dial-admin-backend) is an optional service for backend-managed configuration, import/export, and legacy administration screens. It stores configuration state in its database and exports it for DIAL Core to read.

Admin Frontend can also work directly with Core, without this backend; see Admin Frontend configuration. The settings below apply only when Admin Backend is deployed. They match the backend's configuration guide at release 0.22.5, which lists every property, including OpenTelemetry and actuator settings.

Docker Compose example​

From dial-docker-compose-advanced/dial-2.x/docker-compose-base.yml:

admin-backend:
  image: epam/ai-dial-admin-backend:0.20.1
  platform: linux/amd64
  user: root
  environment:
    ENABLE_CORE_CONFIG_VERSION_AUTO_DETECT: "true"
    CONFIG_EXPORT_OUTPUTFILE_PATH: /app/config/config.json
    CONFIG_REST_SECURITY_MODE: "oidc"
    CORE_CLIENT_URL: "http://core:8080"
    DEBUG_OPTS: "-agentlib:jdwp=transport=dt_socket,server=y,suspend=n,address=*:5006"
    DISABLE_SWAGGER_AUTHORIZATION: true
    ENABLE_CONFIG_AUTO_IMPORT_ON_BOOTSTRAP: "true"
    H2_DATASOURCE_ENCRYPTED_FILE_KEY: ${H2_DATASOURCE_ENCRYPTED_FILE_KEY}
    H2_DATASOURCE_MASTER_KEY: ${H2_DATASOURCE_MASTER_KEY}
    H2_DATASOURCE_PASSWORD: ${H2_DATASOURCE_PASSWORD}
    H2_FILE: ./data/testdb
    METRICS_ENABLED: "false"
    'providers.keycloak.audiences': 'dial-admin-console'
    'providers.keycloak.issuer': "http://${COMMON_HOST}:${KC_PORT}/realms/dial"
    'providers.keycloak.jwk-set-uri': "http://keycloak:${KC_PORT}/realms/dial/protocol/openid-connect/certs"
    'providers.keycloak.role-claims': roles
  volumes:
    - ${DIAL_DIR:-.}/admin/data:/app/data
    - ${DIAL_DIR:-.}/core:/app/config
  depends_on:
    core:
      condition: service_started
  restart: always

Config file export​

Admin Backend periodically exports the managed configuration to a file that DIAL Core reads as its config.json.

VariableDefaultDescription
CONFIG_EXPORT_ENABLEDtrueEnable or disable config file export.
CORE_CONFIG_VERSION—DIAL Core config version for export. Required if auto-detect is disabled.
ENABLE_CORE_CONFIG_VERSION_AUTO_DETECTfalseAuto-detect DIAL Core version from the running instance.
CORE_VERSION_CACHE_EXPIRATION_MS300000Cache expiration for auto-detected version (ms).
CONFIG_EXPORT_SYNCPERIOD15000Export interval (ms).
ENABLE_CONFIG_RELOADtrueWrite config to destination and call DIAL Core's /reload_config endpoint.
DELAY_CONFIG_RELOAD_MILLISECONDS5000Delay before calling /reload_config after writing the file.
ENABLE_CONFIG_AUTO_RELOADfalseEnable automatic scheduled /reload_config calls.
CONFIG_AUTO_RELOAD_SCHEDULE_DELAY_MILLISECONDS120000Interval between auto-reload calls (ms).
CONFIG_EXPORT_STORAGETYPELOCAL_FILEStorage type: LOCAL_FILE, KUBE_SECRET, or CONFIG_MAP.
CONFIG_EXPORT_OUTPUTFILE_PATHdata/export/out.jsonOutput file path (LOCAL_FILE mode).
CONFIG_EXPORT_CONFIGMAP_NAMES—ConfigMap names, comma-separated (CONFIG_MAP mode).
CONFIG_EXPORT_CONFIGMAP_KEYenv.config.jsonKey in the ConfigMap.
CONFIG_EXPORT_KUBESECRET_NAMES—Kubernetes Secret names, comma-separated (KUBE_SECRET mode).
CONFIG_EXPORT_KUBESECRET_KEYkube-secret-keyKey in the Kubernetes Secret.
CONFIG_EXPORT_CREATE_RESOURCESfalseCreate export destination resources if they do not exist.
CONFIG_EXPORT_SYNC_DURATION_THRESHOLD_MS120000Threshold before sync status changes to IN_PROGRESS_TOO_LONG (ms).

DATASOURCE_AUTH_TYPEbasicAuthentication type: basic, azure, or gcp.

Metrics​

These settings serve the legacy telemetry Dashboards: Admin Backend queries the InfluxDB that the legacy Analytics Realtime service writes, as its README notes. New deployments use DIAL Analytics instead: with Admin's Analytics settings and ANALYTICS_USAGE_ENABLED on, the dashboards read DIAL Analytics.

VariableDefaultDescription
METRICS_ENABLEDfalseEnable metrics collection from InfluxDB.
METRICS_CONFIG_CONTENT—Dataset configuration JSON content.
METRICS_CONFIG_FILE—Path to dataset configuration JSON file.
METRICS_DATASOURCE_TYPEinflux2InfluxDB version: influx2 or influx3.
METRICS_STORAGE_HOST—InfluxDB URL. Required if metrics are enabled.
METRICS_STORAGE_TOKEN—InfluxDB access token. Required if metrics are enabled.
METRICS_MAX_TIME_RANGE72hMaximum query time range.
