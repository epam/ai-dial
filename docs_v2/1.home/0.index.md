# Get Started with DIAL

DIAL is an open-source, enterprise-grade platform that gives you a single gateway to language models, a place to build and run AI applications, and the access control, observability, and collaboration features needed to operate them in production.

New to the platform? Read [What is DIAL](../2.understand-dial/1.positioning/1.what-is-dial.md) for the big picture, then return here to pick a path.

:::tip Just want to see DIAL?
Open the hosted edition at [chat.dialx.ai](https://chat.dialx.ai/) — no install, real models, works on any machine.
:::
