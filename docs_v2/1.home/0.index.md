# Get Started with DIAL

DIAL is an open-source, enterprise-grade platform that gives you a single gateway to language models, a place to build and run AI applications, and the access control, observability, and collaboration features needed to operate them in production.

New to the platform? Read [What is DIAL](../2.understand-dial/1.what-is-dial.md) for the big picture, then pick a path below. Use the [documentation directory](#documentation-directory) to browse every section.

:::tip Just want to see DIAL?
Open the hosted edition at **[chat.dialx.ai](https://chat.dialx.ai/)** — no install, real models, works on any machine.
:::

:::tip Want DIAL on your own machine?
Run **[ai-dial-samples](https://github.com/epam/ai-dial-samples)** — DIAL in Docker with small open-source models, so you need no API keys and no cloud account. Start with the **[simple setup](https://github.com/epam/ai-dial-samples/tree/main/1-dial-simple-setup)** for DIAL Chat, DIAL Core, and Quick Apps. Move to the **[advanced setup](https://github.com/epam/ai-dial-samples/tree/main/2-dial-advanced-setup)** for DIAL Admin, evaluations, analytics, a sample agent and interceptor, and role-based access.
:::

:::tip Need the documentation source for your agent?
The original source of this documentation lives in **[ai-dial](https://github.com/epam/ai-dial)**. If your agent needs the source files, pull them from there.
:::
