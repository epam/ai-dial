# Connect to an existing DIAL

In this tutorial, you will call a DIAL deployment that your organization already runs, using the [Unified API](../2.understand-dial/2.architecture/4.unified-api-overview.md) and `curl`. By the end, you will have sent an authenticated chat completion request and received a response. This path is for anyone who already has access to a DIAL instance — you do not need to install or deploy anything.

## Prerequisites

- The endpoint URL of your organization's DIAL deployment and an API key for it. Ask your platform team for both; they are not something you generate yourself.
- A command-line HTTP client (`curl` is used here).

## What you'll do

Send one authenticated request to the Unified API and read the response. The same request shape works against any model or application your platform team has registered — only the host, key, and deployment name change.

## Step 1: Confirm your deployment name

Ask your platform team which deployment to target, or check the model or application list in DIAL Chat if you have UI access. A deployment name is the identifier used in the request path — for example, `gpt-5.6-luna` or `echo`.

**Verify:** you have an endpoint (for example, `https://your-dial-host`), an API key, and a deployment name.

## Step 2: Call the Unified API

Send a chat completion request to your deployment. Authenticate with the `Api-Key` header:

```bash
curl https://your-dial-host/openai/deployments/<DEPLOYMENT_NAME>/chat/completions \
  -H "Api-Key: <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      { "role": "user", "content": "Hello, DIAL" }
    ]
  }'
```

Replace `your-dial-host`, `<DEPLOYMENT_NAME>`, and `<YOUR_API_KEY>` with the values from your platform team.

**Verify:** the response is a JSON object with a `choices` array; `choices[0].message.content` contains the model's or application's reply.

## Step 3: Read the response shape

A typical response looks like this:

```json
{
  "choices": [
    {
      "message": { "role": "assistant", "content": "Hello! How can I help you today?" },
      "finish_reason": "stop"
    }
  ],
  "usage": { "prompt_tokens": 10, "completion_tokens": 9, "total_tokens": 19 }
}
```

`usage` reports token consumption for the request — the same field DIAL Core uses to enforce cost and rate limits on your key.

- How to authenticate to the Unified API with an API key
- How to send a chat completion request to a deployment your organization manages
- What a Unified API response contains
