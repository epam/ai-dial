# Services

This section documents DIAL services and deployment charts: what each is for, how it is configured, and how it is deployed. It is for platform engineers who deploy, configure, and upgrade DIAL. It assumes you know how the services fit together; see [Architecture highlights](../2.understand-dial/4.architecture/1.architecture-highlights.md).

## Services in this section

| Service | Purpose |
|---|---|
| [DIAL Core](1.core/0.index.md) | The API gateway: the Unified API and the other supported AI APIs, access control, usage limits, load balancing, request processing, and resource storage |
| [DIAL Chat](2.chat/0.index.md) | The web interface for users, which can also be embedded in other applications through Chat Overlay |
| [DIAL Chat Themes](3.chat-themes/0.index.md) | The static service that holds the color themes, logos, and icons of DIAL Chat |
| [DIAL Model Provider](4.model-provider/0.index.md) | Runs the OpenAI, Vertex AI, Bedrock, and DIAL-to-DIAL adapters in one service, each under its own `/compat/<adapter>` path; replaces the standalone adapters |
| [DIAL OpenAI Adapter](5.openai-adapter/0.index.md) | Connects models on Azure OpenAI, the OpenAI Platform, Azure AI Foundry, Bedrock OpenAI models, Mistral, Alibaba Cloud, vLLM, and Anthropic Messages providers. Will be deprecated; use DIAL Model Provider |
| [DIAL Bedrock Adapter](6.bedrock-adapter/0.index.md) | Connects the chat, image, and embedding models of Amazon Bedrock, and Claude through the Anthropic API. Will be deprecated; use DIAL Model Provider |
| [DIAL Vertex AI Adapter](7.vertex-ai-adapter/0.index.md) | Connects Gemini, Claude, Imagen, Veo, Mistral, and the embedding models of Google Cloud Vertex AI. Will be deprecated; use DIAL Model Provider |
| [DIAL Quick Apps](8.quick-apps/0.index.md) | Runs Quick Apps, applications composed from tools and an LLM orchestrator, and their visual editor; includes ChatHub |
| [DIAL Admin](9.admin/0.index.md) | The administrator web interface, connected directly to Core, with optional deployment management, evaluation, and analytics services |
| [DIAL Evaluations](10.evaluations/0.index.md) | Evaluation Framework Backend and Evaluation Metrics, which run DIAL Admin's test suites against models, applications, and MCP tools, and score the answers |
| [DIAL Deployment Manager](11.deployment-manager/0.index.md) | Builds images and operates Kubernetes workloads for DIAL Admin, including MCP servers and model servings; includes the stdio MCP proxy images |
| [DIAL Helm](12.helm/0.index.md) | Kubernetes deployment charts for the platform assembly, Core, container-based extensions, and Admin |
| [DIAL OpenAPI to MCP](13.openapi-to-mcp/0.index.md) | An application type that turns a REST API's OpenAPI 3.x document into MCP tools |
| [DIAL RAG](14.rag/0.index.md) | An application that answers questions about the documents attached to a request, indexing them on first use |
| [DIAL Generic RAG](15.generic-rag/0.index.md) | An application type that answers questions over documents uploaded in advance, with a document screen in DIAL Admin |
| [DIAL App Controller](16.app-controller/0.index.md) | Builds Code App images, deploys them as Knative services, and manages interpreter session pods for Core |
| [DIAL App Builder Python](17.app-builder-python/0.index.md) | Build-time helper that downloads and validates Code App sources and prepares a Dockerfile for the image builder |
| [DIAL Code Interpreter](18.code-interpreter/0.index.md) | Executes Python in Jupyter sessions for calculations, file analysis, and visualizations, including Quick Apps tools |
| [DIAL Deep Research](19.deep-research/0.index.md) | Plans research over Generic RAG documents or StatGPT datasets, reviews findings, and produces reports with citations |

Configuration for the other services is still in [Operating DIAL > Configuration](../4.operating-dial/4.configuration/0.index.md) and moves into this section service by service.

## What each service covers

- **Overview** — what the service does, what it depends on, and how it is deployed
- **Configuration** — every setting, with its default, grouped by the entity or subsystem it controls
- **Upstream links** — the service repository, GitHub releases, and published image tags or charts, linked from its overview

Platform releases, which pin a compatible set of service versions in the Helm stable assembly, are in the [Changelog](../8.reference/changelog/index.md).
