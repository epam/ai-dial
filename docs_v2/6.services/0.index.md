# Services

This section documents DIAL services and deployment charts: what each is for, how it is configured, and how it is deployed. It is for platform engineers who deploy, configure, and upgrade DIAL. It assumes you know how the services fit together; see [Architecture highlights](../2.understand-dial/4.architecture/1.architecture-highlights.md).

## Services in this section

| Service | Purpose | Required |
|---|---|---|
| [DIAL Core](1.core/0.index.md) | The API gateway: the Unified API and the other supported AI APIs, access control, usage limits, load balancing, request processing, and resource storage | Yes |
| [DIAL Chat](2.chat/0.index.md) | The web interface for users, which can also be embedded in other applications through Chat Overlay | No |
| [DIAL Chat Themes](3.chat-themes/0.index.md) | The static service that holds the color themes, logos, and icons of DIAL Chat | No |
| [DIAL OpenAI Adapter](4.openai-adapter/0.index.md) | Connects models on Azure OpenAI, the OpenAI Platform, Azure AI Foundry, Bedrock OpenAI models, Mistral, Alibaba Cloud, vLLM, and Anthropic Messages providers | No |
| [DIAL Bedrock Adapter](5.bedrock-adapter/0.index.md) | Connects the chat, image, and embedding models of Amazon Bedrock, and Claude through the Anthropic API | No |
| [DIAL Vertex AI Adapter](6.vertex-ai-adapter/0.index.md) | Connects Gemini, Claude, Imagen, Veo, Mistral, and the embedding models of Google Cloud Vertex AI | No |
| [DIAL Quick Apps](7.quick-apps/0.index.md) | Runs Quick Apps, applications composed from tools and an LLM orchestrator, and their visual editor; includes ChatHub | No |
| [DIAL Admin](8.admin/0.index.md) | The administrator web interface, connected directly to Core, with optional deployment management, evaluation, and analytics services | No |
| [DIAL Evaluations](9.evaluations/0.index.md) | Evaluation Framework Backend and Evaluation Metrics, which run DIAL Admin's test suites against models, applications, and MCP tools, and score the answers | No |
| [DIAL Deployment Manager](10.deployment-manager/0.index.md) | Builds images and operates Kubernetes workloads for DIAL Admin, including MCP servers and model servings; includes the stdio MCP proxy images | No |
| [DIAL Helm](11.helm/0.index.md) | Kubernetes deployment charts for the platform assembly, Core, container-based extensions, and Admin | No |
| [DIAL OpenAPI to MCP](12.openapi-to-mcp/0.index.md) | An application type that turns a REST API's OpenAPI 3.x document into MCP tools | No |
| [DIAL RAG](13.rag/0.index.md) | An application that answers questions about the documents attached to a request, indexing them on first use | No |
| [DIAL Generic RAG](14.generic-rag/0.index.md) | An application type that answers questions over documents uploaded in advance, with a document screen in DIAL Admin | No |

Configuration for the other services is still in [Operating DIAL > Configuration](../4.operating-dial/4.configuration/0.index.md) and moves into this section service by service.

## What each service covers

- **Overview** — what the service does, what it depends on, and how it is deployed
- **Configuration** — every setting, with its default, grouped by the entity or subsystem it controls
- **Upstream links** — the service repository, GitHub releases, and published image tags or charts, linked from its overview

Platform releases, which pin a compatible set of service versions in the Helm stable assembly, are in the [Changelog](../8.reference/changelog/index.md).
