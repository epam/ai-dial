# DIAL Deployment Manager Backend 0.21.0

Backend 0.21.0 adds repository/path-scoped Git credentials and rejects duplicate credential scopes at startup. This reference summarizes the release and its upgrade impact for platform engineers.

## 0.21.0

Released 2026-09-22. [Full release notes](https://github.com/epam/ai-dial-admin-deployment-manager-backend/releases/tag/0.21.0)

**Breaking**

- Startup fails when `TRUSTED_PRIVATE_GIT_REPOS` contains two entries with the same effective host, path, and authentication type. Remove redundant entries before upgrading.

**Added**

- An optional `path` in each Git credential entry scopes it to a repository or group. Selection uses the most-specific matching host and path, rather than array order. Without `path`, credentials retain host-wide scope.
- Backend release images are published for `linux/amd64` and `linux/arm64`, built on Java 21. This does not establish ARM support for every builder, MCP proxy artifact, or workload image.

**Fixed**

- Netty and Bouncy Castle security dependency updates, plus shared CI updates.

The [upgrade guide](https://github.com/epam/ai-dial-admin-deployment-manager-backend/blob/0.21.0/docs/upgrade-plans/0.21.0.md) describes duplicate-scope detection, host/path precedence, and secret handling. No new environment variables are required; the shape and validation of `TRUSTED_PRIVATE_GIT_REPOS` change. See [Private Git repositories](../1.configuration/1.backend.md#private-git-repositories).
