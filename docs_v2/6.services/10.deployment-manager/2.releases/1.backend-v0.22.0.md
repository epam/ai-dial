# DIAL Deployment Manager Backend 0.22.0

Backend 0.22.0 updates runtime dependencies and security checks. This reference summarizes the release for platform engineers upgrading Deployment Manager. The configuration pages use this release's defaults.

## 0.22.0

Released 2026-10-14. [Full release notes](https://github.com/epam/ai-dial-admin-deployment-manager-backend/releases/tag/0.22.0)

**Fixed**

- Spring Boot moves to 4.0.8, Jackson to 3.1.7 / 2.21.7, Vert.x to 4.5.27, Log4j to 2.25.5, and the image's zlib to 1.3.2-r1.

**Other**

- CI's vulnerability gate and SARIF upload include critical, high, medium, and low findings.
- Dependency and build-workflow updates include a pinned Java 21 runtime for the ORT analyzer.

No new application settings are listed in the release notes. Existing [0.21.0 Git credential validation](2.backend-v0.21.0.md) still applies. The backend continues to select the 0.1.0 Alpine/Debian [MCP proxy artifact images](../1.configuration/2.mcp-proxy.md) by default; the backend and artifact images have independent versions.
