# DIAL Deployment Manager MCP proxy 0.1.0

MCP proxy 0.1.0 is the initial release of the executable artifact images used by Deployment Manager's stdio wrappers. This reference is for platform engineers selecting the images for backend builds.

## 0.1.0

Released 2026-01-28. [Full release notes](https://github.com/epam/ai-dial-deployment-manager-mcp-proxy/releases/tag/v0.1.0)

The release provides Alpine and Debian variants. Both package `mcp-proxy==0.10.0` as a standalone executable at `/mcp_proxy`. Backend 0.22.0 selects these artifact images by default:

| Variant | Artifact image |
|---|---|
| Alpine | `ghcr.io/epam/ai-dial-deployment-manager-mcp-proxy:0.1.0-alpine` |
| Debian | `ghcr.io/epam/ai-dial-deployment-manager-mcp-proxy:0.1.0-debian` |

The repository tag is `v0.1.0`; the image tags omit `v` and include the distribution suffix. The artifact release version, Python package version, and Deployment Manager Backend version are separate identifiers. The artifact images supply an executable to a build, rather than a standalone HTTP service.

Only one release is published in the repository as of this page's verification date. See the [Alpine](https://github.com/epam/ai-dial-deployment-manager-mcp-proxy/blob/v0.1.0/alpine/Dockerfile) and [Debian](https://github.com/epam/ai-dial-deployment-manager-mcp-proxy/blob/v0.1.0/debian/Dockerfile) Dockerfiles for the contents and build architecture.
