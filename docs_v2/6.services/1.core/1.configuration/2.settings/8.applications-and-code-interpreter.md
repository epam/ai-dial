# Applications and Code Interpreter

These static settings control whether DIAL Core lists custom applications and how it reaches the services that run Code Apps and Code Interpreter sessions. Applications themselves are dynamic configuration; see [Applications](../7.applications.md). This page is for platform engineers who deploy the application runtime around Core; for who builds and runs each application type, see [Application hosting and lifecycle](../../../../2.understand-dial/4.architecture/6.application-server.md).

## Applications

| Setting | Default | Description |
|---|---|---|
| `applications.includeCustomApps` | `true` | Whether applications are included in the OpenAI-style deployment listing. Code Apps, Custom Apps, Quick Apps, and similar applications need it. |
| `applications.controllerEndpoint` | — | The endpoint of [App Controller](../../../16.app-controller/0.index.md), which manages deployments for applications with functions. |
| `applications.controllerTimeout` | `240000` | The timeout of operations against the Application Controller, in milliseconds. |
| `applications.controllerConnectTimeout` | `10000` | The connection timeout for requests to App Controller, in milliseconds. |

Controller timeout defaults are read by [Core 0.49.4's ApplicationOperatorService](https://github.com/epam/ai-dial-core/blob/0.49.4/server/src/main/java/com/epam/aidial/core/server/service/ApplicationOperatorService.java#L39-L44). Controller Kubernetes, image-build, and workload settings are documented in [App Controller configuration](../../../16.app-controller/1.configuration.md).

## Code Interpreter

| Setting | Default | Description |
|---|---|---|
| `codeInterpreter.sessionImage` | — | The container image for [Code Interpreter](../../../18.code-interpreter/0.index.md) sessions. |
| `codeInterpreter.sessionProxyUrl` | — | When set, a session is deployed as a pod instead of a Knative deployment, and all requests to it go through an nginx proxy at this URL. |
| `codeInterpreter.sessionTtl` | `600000` | How long a session lives after its last API call, in milliseconds. |
| `codeInterpreter.checkPeriod` | `10000` | How often Core checks active sessions for expiration, in milliseconds. |
| `codeInterpreter.checkSize` | `256` | The maximum number of active sessions checked in one pass. |

Who may create Code Apps or run Code Interpreter is set by `access.createCodeAppRoles`; see [Access](7.access.md).

For the interpreter container's own environment, Quick Apps connection, and calculation-tool setup, see [Code Interpreter configuration](../../../18.code-interpreter/1.configuration.md).

## Example

```json
{
  "applications": {
    "includeCustomApps": true,
    "controllerEndpoint": "http://dial-app-controller:8080"
  },
  "codeInterpreter": {
    "sessionImage": "epam/ai-dial-code-interpreter:0.2.0",
    "sessionTtl": 600000
  }
}
```
