# DIAL Chat Themes 0.20.0

DIAL Chat Themes 0.20.0 aligns the light theme's control tokens with DIAL UI Kit 0.14.0, a breaking change for custom themes built on the old token names. This page summarizes the release and its patch release, 0.20.1, with a link to the full notes of each. It is for platform engineers who plan an upgrade of the themes service.

Platform release 1.48 ships DIAL Chat Themes 0.20.0; see [Upgrade to DIAL 1.48](../../../8.reference/changelog/upgrade-to-1.48.md).

| Version | Date | Type |
|---|---|---|

## 0.20.0

Released 2026-09-14. [Release notes](https://github.com/epam/ai-dial-chat-themes/releases/tag/0.20.0)

**Breaking**

- The light theme's control tokens are aligned with DIAL UI Kit 0.14.0. A custom theme that still uses the old names renders the built-in light values for them; see [Renamed tokens](../1.configuration.md#renamed-tokens).

**Added**

- Eva and COI icons.
- ChatHub, Mind-Map, and RAG_files_search icons resized to 20 × 20.

## Patch releases

### 0.20.1

Released 2026-10-05. [Release notes](https://github.com/epam/ai-dial-chat-themes/releases/tag/0.20.1)

- **Fixed:** the Docker base image upgraded, with an `apk upgrade` step.
