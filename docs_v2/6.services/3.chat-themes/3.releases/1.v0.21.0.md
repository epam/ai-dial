# DIAL Chat Themes 0.21.0

DIAL Chat Themes 0.21.0 adds a dark theme with the DIAL UI Kit tokens, new shadow and accent-focus tokens for the light theme, and arm64 images. This page summarizes the release and its patch release, 0.21.1, with a link to the full notes of each. It is for platform engineers who plan an upgrade of the themes service.

| Version | Date | Type |
|---|---|---|
| [0.21.0](#0210) | 2026-10-09 | Minor release |
| [0.21.1](#0211) | 2026-10-26 | Patch |

## 0.21.0

Released 2026-10-09. [Release notes](https://github.com/epam/ai-dial-chat-themes/releases/tag/0.21.0)

**Added**

- A dark theme.
- Semantic shadow and accent-focus tokens in the light theme, for the DIAL UI Kit.
- New accent color properties in `config.json`.
- `linux/arm64` image builds.

**Fixed**

- Updated color values in `config.json`.
- An `expat` upgrade and adjusted user permissions in the Docker image.

## Patch releases

### 0.21.1

Released 2026-10-26. [Release notes](https://github.com/epam/ai-dial-chat-themes/releases/tag/0.21.1)

- **Fixed:** the nginx base image upgraded to 1.31.7.
