# Quick Apps Frontend 0.2.0

Quick Apps Frontend 0.2.0 is a bug-fix release of the editor. It has no patch releases. This page summarizes the release, with a link to its full notes. It is for platform engineers who plan a Quick Apps upgrade.

| Version | Date | Type |
|---|---|---|
| [0.2.0](#020) | 2026-09-22 | Minor release |

## 0.2.0

Released 2026-09-22. [Release notes](https://github.com/epam/ai-dial-quickapps-frontend/releases/tag/0.2.0)

**Fixed**

- Toolsets and agents removed from DIAL are handled in the editor.
- Toolsets added through JSON are displayed.
- Files can be downloaded from the **Context files** dialog.
