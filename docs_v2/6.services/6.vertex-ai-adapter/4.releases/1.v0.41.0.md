# DIAL Vertex AI Adapter 0.41.0

DIAL Vertex AI Adapter 0.41.0 routes all upstream clients through one shared, configurable connection pool, makes the keep-alive timeout configurable, and moves the server to uvloop and httptools; patch 0.41.1 adds Gemini Transcribe. This page summarizes the release and its patch releases, 0.41.1 and 0.41.2, with a link to the full notes of each. It is for platform engineers who plan an adapter upgrade.

## 0.41.0

Released 2026-10-14. [Release notes](https://github.com/epam/ai-dial-adapter-vertexai/releases/tag/0.41.0)

**Added**

- Configurable upstream connection pool limits, with `503` when the pool is exhausted. See [Server and connections](../3.configuration.md#server-and-connections).
- `TIMEOUT_KEEP_ALIVE` for the server's keep-alive timeout.
- One shared HTTP client for all upstream SDK clients.
- The server runs on uvloop and httptools.

**Fixed**

- Gemini keeps the thought signatures of generated images.
- API key integrations share one connection pool across upstream clients.
- A cancelled caller no longer poisons the cache.
- Blocking embedding calls run on a shared thread pool.

**Changed**

- Faster OpenTelemetry Protobuf export, and upgrades of `aidial-adapter-anthropic` to 0.19.0 and `aidial-sdk` to 0.45.0.
