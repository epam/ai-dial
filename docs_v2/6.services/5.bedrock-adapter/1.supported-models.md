# Supported models

The DIAL Bedrock Adapter serves a fixed list of Amazon Bedrock models, addressed by their Bedrock model IDs in the adapter URL. This reference lists them with the features each supports. It is for platform engineers who choose which Bedrock models to offer in DIAL; the list follows the adapter's `development` branch, so check the release you run.

Every chat model supports `/configuration`. Claude uses the Anthropic SDK or the Converse API, Stability AI models the original Bedrock API, and the others the Converse API.

### Token counting

Every chat model supports `/truncate_prompt` and the `max_prompt_tokens` parameter, and every model except the Stability AI ones supports `/tokenize`. Accuracy differs:

- **Exact** for Claude 5, Claude 4.8 and 4.7 Opus, and the Mantle Claude 4.5 Haiku (`anthropic.claude-haiku-4-5`), when they use the `mantle` client. See [Claude clients](2.capabilities.md#claude-clients).
- **Approximate** for every other model, because the vendors do not publish their tokenizers. The adapter counts each byte of the UTF-8 text as one token, which overestimates.

### Cross-region inference

Models that support cross-region inference also take the region prefixes `us.`, `eu.`, and `apac.`, for example `us.anthropic.claude-3-5-sonnet-20241022-v2:0`. Check that your AWS account supports cross-region inference for the model first.

## Embedding models

These models serve `POST /openai/deployments/<model id>/embeddings`.

| Model | Model ID | Input |
|---|---|---|
| Titan Multimodal Embeddings G1 | `amazon.titan-embed-image-v1` | Text, images |
| Titan Text Embeddings V2 | `amazon.titan-embed-text-v2:0` | Text |
| Titan Embeddings G1 – Text v1.2 | `amazon.titan-embed-text-v1` | Text |
| Cohere Embed English | `cohere.embed-english-v3` | Text |
| Cohere Embed Multilingual | `cohere.embed-multilingual-v3` | Text |

## A model not on the list

When Bedrock releases a model the adapter does not know yet, serve it through a compatible model the adapter does know. See [Compatibility mode](2.capabilities.md#compatibility-mode).
