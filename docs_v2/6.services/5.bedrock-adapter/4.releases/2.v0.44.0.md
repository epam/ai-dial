# DIAL Bedrock Adapter 0.44.0

DIAL Bedrock Adapter 0.44.0 upgrades the DIAL SDK; its patches bound the AWS client caches and move blocking AWS calls to a shared thread pool. This page summarizes the release and its patch releases, 0.44.1 and 0.44.2, with a link to the full notes of each. It is for platform engineers who plan an adapter upgrade.

Platform release 1.48 ships DIAL Bedrock Adapter 0.44.0; see [Upgrade to DIAL 1.48](../../../8.reference/changelog/upgrade-to-1.48.md).

## 0.44.0

Released 2026-09-22. [Release notes](https://github.com/epam/ai-dial-adapter-bedrock/releases/tag/0.44.0)

- **Changed:** `aidial-sdk` upgraded from 0.39.0 to 0.42.0.

## Patch releases

### 0.44.1

Released 2026-09-29. [Release notes](https://github.com/epam/ai-dial-adapter-bedrock/releases/tag/0.44.1)

- **Fixed:** the AWS client caches keyed by session tags are bounded.

### 0.44.2

Released 2026-10-02. [Release notes](https://github.com/epam/ai-dial-adapter-bedrock/releases/tag/0.44.2)

- **Fixed:** blocking AWS calls run on a shared thread pool, and Botocore timeouts are bounded.
