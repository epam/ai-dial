# DIAL Bedrock Adapter 0.45.0

DIAL Bedrock Adapter 0.45.0 answers `503` when the Anthropic connection pool is exhausted, makes the keep-alive timeout configurable, and moves the server to uvloop and httptools. This page summarizes the release and its patch release, 0.45.1, with a link to the full notes of each. It is for platform engineers who plan an adapter upgrade.

| Version | Date | Type |
|---|---|---|
| [0.45.0](#0450) | 2026-10-14 | Minor release |
| [0.45.1](#0451) | 2026-10-29 | Patch |

## 0.45.0

Released 2026-10-14. [Release notes](https://github.com/epam/ai-dial-adapter-bedrock/releases/tag/0.45.0)

**Added**

- A `503` answer, at once, when the Anthropic connection pool is exhausted. See [Resource limits](../3.configuration.md#resource-limits).
- `TIMEOUT_KEEP_ALIVE` for the server's keep-alive timeout.
- The server runs on uvloop and httptools.

**Fixed**

- No warning for session tag paths into unset optional UserInfo fields.

**Changed**

- Faster OpenTelemetry Protobuf export, and upgrades of `aidial-adapter-anthropic` to 0.19.0 and `aidial-sdk` to 0.45.0.

## Patch releases

### 0.45.1

Released 2026-10-29. [Release notes](https://github.com/epam/ai-dial-adapter-bedrock/releases/tag/0.45.1)

- **Changed:** `pip` removed from the image; dependency upgrades, including `aidial-sdk` 0.46.0, `aidial-adapter-anthropic` 0.20.0, and `aiohttp` 3.14.4.
