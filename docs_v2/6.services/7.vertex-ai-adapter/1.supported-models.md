# Supported models

The DIAL Vertex AI Adapter serves a fixed list of Vertex AI models, addressed by their Vertex AI model IDs in the adapter URL. This reference lists them with the input they take and the features they support. It is for platform engineers who choose which Vertex AI models to offer in DIAL; the list follows the adapter's `development` branch, so check the release you run.

### Features by family

| Family | `/tokenize` | `/truncate_prompt` and `max_prompt_tokens` | Tools | `/configuration` |
|---|---|---|---|---|
| Gemini 2.5 and later | Yes | Yes | Yes, except Gemini 3.5 Transcribe | Yes, except Gemini 3.5 Transcribe |
| Gemini 2.0 | Yes | Yes | Yes | No |
| Claude | Yes | Yes | Yes | Yes |
| Imagen, Veo | Yes | Yes | No | Yes |
| Mistral | No | No | Yes | No |

### Models with special behavior

- **Gemini 3.5 Transcribe** accepts audio attachments only. It rejects system messages and text input, and the adapter sends only the last message, so each DIAL Chat message is transcribed on its own.
- **Gemini 2.5 Flash Image and Gemini 3 Pro Image** generate and edit images: a follow-up such as "replace the cat with a dog" edits the previous image. DIAL Chat removes attachments from assistant messages by default, so for editing in Chat, set `features.assistantAttachmentsInRequestSupported: true` on the model.
- **Veo** takes the text and files of the last user message only. An image can come as an image content part or an attachment; a video, as an attachment.

## Embedding models

These models serve `POST /openai/deployments/<model id>/embeddings`.

| Model | Model ID | Language | Input |
|---|---|---|---|
| Gemini Embedding 2 | `gemini-embedding-2-preview` | English | Text, image, video, audio, PDF |
| Gemini Embeddings | `gemini-embedding-001` | Multilingual | Text |
| Multimodal embeddings | `multimodalembedding@001` | English | Text, image |
| Embeddings for Text | `text-embedding-004`, `text-embedding-005` | English | Text |

Multimodal input goes in `custom_input` as DIAL attachments, each with a MIME `type` and a `url` or base64 `data`. Several parts can form one composite input. Gemini Embedding 2 does not accept instruction prompts, so leave `custom_fields.instruction` unset.

## A model not on the list

When Vertex AI releases a model version the adapter does not know yet, serve it through a compatible model the adapter does know. See [Compatibility mode](2.capabilities.md#compatibility-mode).
