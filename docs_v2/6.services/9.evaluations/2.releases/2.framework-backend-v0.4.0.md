# Evaluation Framework Backend 0.4.0

Evaluation Framework Backend 0.4.0 adds multi-request test suites, OpenAI Responses and Anthropic Messages targets, and run costs. This page summarizes the release for platform engineers who plan an upgrade. There are no patch releases.

## 0.4.0

Released 2026-09-22. [Full release notes](https://github.com/epam/ai-dial-admin-evaluation-framework-backend/releases/tag/0.4.0)

**Added**

- Test suites for deployments that use the OpenAI Responses API and the Anthropic Messages API.
- Multi-request test suites, with **Try Out** for them.
- Endpoints for run costs and deployment costs.
- An overall score per test case.
- A status update when a run is cancelled.
- Validation of deployment IDs, and deployment lookup through DIAL Core's `/v1/deployments/{id}` endpoint.
- The display name of the author in a test suite's **Created by**, when `SECURITY_JWT_RESOLVE_USER_NAME` is `true`.
- Configuration of the `extra` metric provider through environment variables.

**Fixed**

- Saving an empty required tool argument (#174).
- Raw SQL in error messages (#172).
