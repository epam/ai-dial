# Evaluation Metrics 0.1.0

Evaluation Metrics 0.1.0 is the first release of the metrics service. This page summarizes it and its patch release, 0.1.1, for platform engineers who deploy the service.

## 0.1.0

Released 2026-07-29. [Full release notes](https://github.com/epam/ai-dial-admin-evaluation-metrics/releases/tag/0.1.0)

- A stateless FastAPI service that scores answers against expected data. It provides rule-based metrics (Exact Match, Regex Match, set comparison, and DeepDiff) and LLM metrics from DeepEval, Ragas, and DIAL RAG Eval. The metric catalog is served by its API.
- Settings for the DIAL Core connection (`DIAL_URL`, `DIAL_API_KEY`), concurrency (`EVAL__APP__*`), the judge models of each metric group (`EVAL__METRICS__*`), and logging (`LOG_LEVEL`, `LOG_LEVEL_OVERRIDE`). See [Metrics configuration](../1.configuration/2.metrics.md).
- `nltk` is upgraded to 3.10.0 for a security advisory.
