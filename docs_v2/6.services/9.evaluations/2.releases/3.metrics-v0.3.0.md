# Evaluation Metrics 0.3.0

Evaluation Metrics 0.3.0 adds structured logs and stops downloading tokenizer files at runtime. This page summarizes the release for platform engineers who plan an upgrade. There are no patch releases.

## 0.3.0

Released 2026-09-22. [Full release notes](https://github.com/epam/ai-dial-admin-evaluation-metrics/releases/tag/0.3.0)

**Added**

- Structured (JSON) logs, provided by the DIAL SDK. `DIAL_SDK_LOG_FORMAT` selects `text` or `json`, and `DIAL_SDK_TEXT_LOG_FORMAT` and `DIAL_SDK_JSON_LOG_FORMAT` set the formats. See [Logging and telemetry](../1.configuration/2.metrics.md#logging-and-telemetry).

**Fixed**

- The `cl100k_base.tiktoken` tokenizer file is bundled in the image and no longer downloaded at runtime.

**Other**

- `pip` is removed from the image. `anyio`, `aiohttp`, `nltk`, and `setuptools` are updated.
