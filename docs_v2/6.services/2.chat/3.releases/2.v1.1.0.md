# DIAL Chat 1.1.0

DIAL Chat 1.1.0 adds skills, a prompt library, Scheduled Tasks, MCP Apps, the Settings page, voice dictation, the Responses API path, and the operator-controlled UI feature list. This page summarizes the release and its patch releases, 1.1.1 to 1.1.19, with a link to the full notes of each. It is for platform engineers who plan a DIAL Chat upgrade; each GitHub release lists every change and its deployment notes.

Platform release 1.48 ships DIAL Chat 1.1.0; see [Upgrade to DIAL 1.48](../../../8.reference/changelog/upgrade-to-1.48.md).

## 1.1.0

Released 2026-09-22. [Release notes](https://github.com/epam/ai-dial-chat/releases/tag/1.1.0)

**Added**

- Skills end to end: upload, an authoring editor, details, ZIP import, sharing, and publishing. Using a skill in a conversation ships behind `SKILL_USAGE_ENABLED`.
- A saved-prompt library with an editor, favorites, sharing, publishing, and prompt parameters with default values.
- Scheduled Tasks through DIAL Scheduler, with run history and an offline-credentials consent flow.
- MCP Apps in an isolated-origin sandbox, a deployments catalog with MCP filtering, and personal and organization toolset credentials.
- Custom schema apps, and a rewritten toolset editor.
- A Settings page with a Preferences tab and per-user usage, and a redesigned Limits tab.
- Responses API generations, behind `RESPONSES_API_ENABLED`.
- Voice dictation with an editable transcript.
- OOXML, spreadsheet, CSV, HTML, and code previews, and citations that open the cited page or table row.
- `APPLICATION_VISUALIZERS`, ported from Chat 0.x.
- The overlay method surface, external and same-window login for embeds, and the `ENABLED_UI_FEATURES` allowlist.
- The announcement banner and popover, a footer with a version label, and start-screen copy.
- Bearer-token authentication for API clients, `CUSTOM_CLIENT_VARIABLES`, and private CA support through `NODE_EXTRA_CA_CERTS`.
- OpenTelemetry traces and metrics, and a 62% smaller initial bundle.

**Fixed**

- A generation keeps running when the browser disconnects, bounded by `MAX_GENERATION_DURATION_MS`, and a concurrent generation answers `409`.
- Leaks in server-sent event streams are closed.
- Many fixes to conversations, files, citations, skills, Quick Apps, custom apps, and toolset sign-in.

**Security**

- Per-response style nonces and `CSP_MODE`, with `report-only` as the default.
- Path traversal in toolset names is rejected, and deployment IDs are validated in every route.
- Toolset API keys and client secrets are masked in the editor.
- `AUTH_LEGACY_COOKIE_NAMES` expires cookies left by a previous auth stack.

**Changed on upgrade from 1.0.18**

- New variables: `CUSTOM_CLIENT_VARIABLES`, `WELCOME_SCREEN_DESCRIPTION`, `SKILL_USAGE_ENABLED`, and `APPLICATION_VISUALIZERS`.
- Removed: `SETTINGS_PAGE_ENABLED` and `SETTINGS_PAGE_ENABLED_ROLES`; the Settings page is always on.
- New UI feature keys: `removable-tools`, `show-all-starters`, and `hide-footer-version`.

## Patch releases

### 1.1.1

Released 2026-09-24. [Release notes](https://github.com/epam/ai-dial-chat/releases/tag/1.1.1)

- **Added:** start-page celebrations, selected by `UI_EVENT`.
- **Fixed:** a server-enforced rolling session lifetime, `AUTH_SESSION_MAX_AGE_SECONDS`; a stale generation's save no longer overwrites a newer one; generated titles drop characters DIAL Core rejects.
- **Changed on upgrade:** every user signs in again, and the session lifetime no longer depends on `offline_access`. Deploy all `chat-api` replicas together.

### 1.1.2

Released 2026-09-25. [Release notes](https://github.com/epam/ai-dial-chat/releases/tag/1.1.2)

- **Added:** the `show-agent-description`, `show-header-logo`, `disable-input-history-navigation`, `hide-conversation-export`, and `hide-settings-page` UI feature keys.
- **Fixed:** `HTTP_PROXY`, `HTTPS_PROXY`, and `NO_PROXY` are honored; PDFs open at the cited page from the Sources panel.
- **Changed on upgrade:** proxy variables already in the container now take effect. Add internal hosts to `NO_PROXY` first.

### 1.1.3

Released 2026-09-25. [Release notes](https://github.com/epam/ai-dial-chat/releases/tag/1.1.3)

- **Changed:** the image moves to `node:24.21-alpine3.24` with a patched npm.

### 1.1.4

Released 2026-09-25. [Release notes](https://github.com/epam/ai-dial-chat/releases/tag/1.1.4)

- **Added:** `ALLOWED_CONNECT_ORIGINS`, for PDF and Office previews from trusted document origins.
- **Fixed:** `proxy-addr` and `multer` upgrades for reported vulnerabilities.

### 1.1.5

Released 2026-09-26. [Release notes](https://github.com/epam/ai-dial-chat/releases/tag/1.1.5)

- **Fixed:** the Sources toggle on mobile and in narrow overlay iframes, and full document names in tooltips.

### 1.1.6

Released 2026-09-28. [Release notes](https://github.com/epam/ai-dial-chat/releases/tag/1.1.6)

### 1.1.7

Released 2026-09-29. [Release notes](https://github.com/epam/ai-dial-chat/releases/tag/1.1.7)

- **Fixed:** a failed generation offers Try again, an answer stays on screen when its final save fails, and long generations recover after the device sleeps or the network drops.

- **Changed on upgrade:** `false`, `0`, and `no` now turn off `SCHEDULED_TASKS_ENABLED`, `LIVE_CHAT_INTERACTION_ENABLED`, and `LLM_CONVERSATION_NAMING_ENABLED`.
