# DIAL Chat 1.2.0

DIAL Chat 1.2.0 adds several skills per message, Refine with AI, Start now for scheduled tasks, background Responses generations, a redesigned File Manager, and two more container images. This page summarizes the release and its patch releases, 1.2.1 to 1.2.22, with a link to the full notes of each. It is for platform engineers who plan a DIAL Chat upgrade; each GitHub release lists every change and its deployment notes.

Platform releases, which pin DIAL Chat together with the other services, are in the [Changelog](../../../8.reference/changelog/index.md).

## 1.2.0

Released 2026-10-14. [Release notes](https://github.com/epam/ai-dial-chat/releases/tag/1.2.0)

**Added**

- Several skill mentions in one message, inserted with `/` at the caret. Skills are on in every deployment; `SKILL_USAGE_ENABLED` is removed.
- Skill Editor file management: create folders, upload files and archives, and browse the DIAL file system.
- Skills on scheduled tasks, **Start now** to run a task at once, and a Completed badge for finished tasks.
- **Refine with AI** for descriptions and instructions, using `UTILITY_MODEL`, with prompt-override variables. See [Models and generation](../1.configuration/4.models-and-generation.md#prompt-overrides).
- One Metadata | Setup layout for every entity editor, and a full-page Quick App preview.
- Creating an application from every runner in the Create menu, and a settings form generated from a runner's JSON schema.
- Authenticating an application's external services before a conversation, and publishing a toolset with the publisher's own credentials.
- A redesigned File Manager with an All tab, and per-file cancel in the transfer queue.
- A banner that warns about running-low day, week, or month limits. The usage dial moves behind `USAGE_LIMITS_CONTROL_ENABLED`.
- Background Responses generations, behind `RESPONSES_BACKGROUND_ENABLED`; they need DIAL Core 0.48.0 or later.
- The custom Core API bridge, behind `CUSTOM_CORE_API_CONFIG`.
- Nested agent stages, and expandable stage attachments such as RAG search results.
- Every theme the themes host serves in the theme picker, and SVG favicons.
- Copy and Reply actions on messages, and a QR code for share links.
- Two new images: `epam/ai-dial-chat-bff` and `epam/ai-dial-chat-mcp-app-sandbox`.

**Fixed**

- Large conversations no longer freeze the page, and very long code renders as plain text instead of hanging.
- Answers survive reloads and failed saves, and a reload rejoins a running generation.
- Large uploads stream to DIAL Core with an idle timeout instead of failing at `FILE_TRANSFER_TIMEOUT_MS`.
- HTML attachments preview under their own CSP, so `CSP_MODE=enforce` no longer blocks them.
- Many fixes to scheduled tasks, skills, the Catalog, the File Manager, Quick Apps, toolset sign-in, MCP Apps, and citations.
- OIDC client and issuer requests now use the configured proxy.

**Security**

- Scheduled-task routes answer `403` while `SCHEDULED_TASKS_ENABLED` is off.
- Path segments `.` and `..` are rejected in application and skill IDs.
- Application `function.env` and several sensitive bodies are no longer logged.

**Changed on upgrade**

- `CORS_ORIGIN` and `AUTH_POST_LOGOUT_REDIRECT_URI` default to `AUTH_CALLBACK_BASE_URL`.
- The `FILE_MANAGER_AVAILABLE_TABS` default gains `all`.
- The usage dial is hidden unless `USAGE_LIMITS_CONTROL_ENABLED=true`.
- New variables: `RESPONSES_BACKGROUND_ENABLED`, `CUSTOM_CORE_API_CONFIG`, `USAGE_LIMITS_CONTROL_ENABLED`, `USAGE_LIMITS_WARNING_THRESHOLD_PERCENT`, `MCP_APP_HOST_NAME`, and the prompt overrides.
