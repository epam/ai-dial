# DIAL platform chart 8.0.0

Platform chart 8.0.0 moves the assembly to Chat 1.x and removes the bundled Keycloak dependency. This reference summarizes the breaking deployment changes for platform engineers upgrading from chart 7.x.

## 8.0.0

Released 2026-09-23. [Chart release notes](https://github.com/epam/ai-dial-helm/releases/tag/dial-8.0.0)

**Breaking**

- The chart no longer deploys or manages Keycloak. Existing chart-managed Keycloak installations need a backed-up and working external replacement before old resources are retired. Remove obsolete `keycloak` values only as part of that migration.
- The bundled Chat moves from `0.49.0` to `1.1.0`. Custom sign-in and application variables must be migrated to Chat 1.x; retaining the old names does not configure the new application.

The upstream [8.0 upgrade guide](https://github.com/epam/ai-dial-helm/blob/dial-8.0.0/charts/dial/README.md#to-800) describes the sequence, including preserving the Keycloak database/configuration and delaying deletion of old resources until the replacement works. The [Chat migration guide](https://github.com/epam/ai-dial-chat/blob/1.1.0/docs/legacy-chat-migration-guide.md) lists the application changes.

These changes continue to apply to later 8.x charts. The chart release packages platform assembly 1.48.0; chart, assembly, and service versions are distinct.
