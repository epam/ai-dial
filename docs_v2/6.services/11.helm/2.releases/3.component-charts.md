# DIAL component chart releases

Admin, Core, and Extension charts are released independently from the platform chart. This reference lists their latest two published versions as of verification, with deployment changes relevant to platform engineers. Versions here identify Helm packages, not service images.

## Admin chart

| Chart version | Date | Deployment context |
|---|---|---|
| [0.20.0](https://github.com/epam/ai-dial-helm/releases/tag/dial-admin-0.20.0) | 2026-10-16 | Bundles Admin Frontend `0.22.0`, Admin Backend `0.22.1`, and optional Deployment Manager `0.22.0`; frontend/manager use Extension chart `3.1.1`. |
| [0.19.0](https://github.com/epam/ai-dial-helm/releases/tag/dial-admin-0.19.0) | 2026-09-23 | Previous Admin chart release. Its image versions and defaults are in the [tagged values](https://github.com/epam/ai-dial-helm/blob/dial-admin-0.19.0/charts/dial-admin/values.yaml). |

Admin chart `appVersion` refers to the Admin application line. It does not pin every component to one shared tag. Manager remains disabled by default, while frontend, backend, and bundled PostgreSQL are enabled. See [Admin chart configuration](../1.configuration/4.dial-admin.md).

## Core chart

| Chart version | Date | Deployment context |
|---|---|---|
| [6.0.0](https://github.com/epam/ai-dial-helm/releases/tag/dial-core-6.0.0) | 2026-06-24 | Replaces the Redis chart dependency with Valkey. Uses a `valkey` values subtree and Valkey authentication/configuration. |
| [5.2.1](https://github.com/epam/ai-dial-helm/releases/tag/dial-core-5.2.1) | 2026-05-28 | Previous published Core chart release; inspect its [tagged values](https://github.com/epam/ai-dial-helm/blob/dial-core-5.2.1/charts/dial-core/values.yaml) before carrying overrides forward. |

For the cache migration, review the platform chart's [7.0.0 upgrade instructions](https://github.com/epam/ai-dial-helm/blob/dial-8.1.0/charts/dial/README.md#to-700). Old `redis.*` chart values do not become `valkey.*` overrides automatically. External-cache setups disable the bundled dependency and supply Core's connection settings directly. Preserve Core encryption and durable data throughout the upgrade.

## Extension chart

| Chart version | Date | Deployment context |
|---|---|---|
| [3.1.1](https://github.com/epam/ai-dial-helm/releases/tag/dial-extension-3.1.1) | 2026-05-28 | Fixes a duplicate `matchLabels` key when rendering `ingressNSPodMatchLabels` in network policy. |
| [3.1.0](https://github.com/epam/ai-dial-helm/releases/tag/dial-extension-3.1.0) | 2026-05-18 | Adds HTTPRoute configuration for Gateway API routing. |

These changes affect standalone Extension releases and charts that pin Extension as a dependency. Upgrading a separately installed Extension chart does not change the dependency packaged inside another installed release.
