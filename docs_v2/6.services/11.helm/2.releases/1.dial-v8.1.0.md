# DIAL platform chart 8.1.0

Platform chart 8.1.0 packages DIAL assembly 1.49.0. This reference records its chart dependencies and image defaults for platform engineers reviewing an upgrade; application changes remain in the platform changelog.

## 8.1.0

Released 2026-10-16. [Chart release notes](https://github.com/epam/ai-dial-helm/releases/tag/dial-8.1.0)

The [chart metadata](https://github.com/epam/ai-dial-helm/blob/dial-8.1.0/charts/dial/Chart.yaml) sets `appVersion: 1.49.0` and pins Core chart `6.0.0` and Extension chart `3.1.1`. Its service image tags are listed in [Platform chart configuration](../1.configuration/1.dial.md#dependencies-and-images).

| Service | Default image tag |
|---|---|
| Core | `0.49.2` |
| Chat | `1.2.4` |
| Chat Themes | `0.21.0` |
| OpenAI / Bedrock adapters | `0.45.0` |
| Vertex AI adapter | `0.41.1` |
| DIAL adapter | `0.20.0` |

The chart retains 8.0.0's deployment model: Keycloak is external, and Chat uses the 1.x configuration surface. Upgrading from 7.x still requires the [8.0.0 migration](2.dial-v8.0.0.md).

Admin is a separate chart release, `dial-admin` 0.20.0. A platform chart upgrade does not upgrade a separate Admin release. See [Component chart releases](3.component-charts.md).
