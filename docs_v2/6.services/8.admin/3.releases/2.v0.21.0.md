# DIAL Admin Frontend 0.21.0

Admin Frontend 0.21.0 introduces the direct DIAL Core configuration migration as Preview and hides backend-dependent screens when Admin Backend is absent. This reference summarizes the release and patches through 0.21.4 for platform engineers planning an upgrade.

## 0.21.0

Released 2026-09-22. [Full release notes](https://github.com/epam/ai-dial-admin-frontend/releases/tag/0.21.0)

- The Preview **Catalog** group reads and writes Core configuration directly: models, interceptors, routes, application runners, roles, keys, and translators. Platform applications and toolsets are available alongside public resources.
- File-defined configuration can be inspected in read-only views.
- When `DIAL_ADMIN_API_URL` is unset, backend-dependent Entities, Builders, Access Management, Activity Audit, and configuration-transfer screens are hidden.
- Evaluation [Preview] adds multi-request test suites, run cancellation, richer execution details, and trend cards. The evaluation services have their own [releases](../../9.evaluations/0.index.md#releases).
- Analytics [Preview] expands the conversation trace view, query tools, table schemas, and enrichment/aggregation pipelines.

The release's [upgrade guide](https://github.com/epam/ai-dial-admin-frontend/blob/0.21.0/docs/upgrade-plans/0.21.0.md) recommends hiding `catalog` while the Core migration is Preview. In 0.22, navigation changes again; use the configuration and menu keys for the release you deploy.
