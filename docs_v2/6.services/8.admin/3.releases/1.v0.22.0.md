# DIAL Admin Frontend 0.22.0

Admin Frontend 0.22.0 reorganizes navigation into AI Gateway, Artifacts, and Governance, adopts [UI Kit](../../../3.building-with-dial/6.developer-tools/3.ui-libraries/1.ui-kit.md) 2.0, and expands evaluation and analytics. This reference summarizes deployment changes and patches through 0.22.5 for platform engineers planning an upgrade.

## 0.22.0

Released 2026-10-14. [Full release notes](https://github.com/epam/ai-dial-admin-frontend/releases/tag/0.22.0)

- Navigation replaces Catalog, Assets, and Approvals with AI Gateway, Artifacts, and Governance. Update obsolete `assets` and `approvals` values in `DISABLE_MENU_ITEMS` to `aigateway`, `artifacts`, `governance`, or item-specific keys.
- The default theme changes to light. Custom themes must supply the UI Kit 2.0 token families.
- Catalog schema authoring, route configuration, and additional file-defined entity views extend Core administration. Global settings add the rate-limit reset calendar.
- Evaluation [Preview] adds OpenAI Responses and Anthropic Messages test suites and improves test authoring, run summaries, and comparisons. The evaluation services have their own [releases](../../9.evaluations/0.index.md#releases); the advanced setup sample pairs Admin Frontend 0.22.1 with Framework Backend 0.5.0 and Metrics 0.3.0.
- Analytics [Preview] adds configuration transfers independent of Admin Backend, richer dashboards, and pipeline runtime controls. Conversations becomes **Sessions**, with `ANALYTICS_SESSIONS_ENABLED` replacing the old conversations flag.
- `ANALYTICS_USAGE_ENABLED` gates Analytics Dashboards; `DIAL_ANALYTICS_RUNNER_API_URL` connects pipeline runtime controls. ZIP imports gain configurable entry and expanded-size limits. See [Admin Frontend configuration](../2.configuration/1.frontend.md).
- The container starts Next.js through `node` and no longer includes `npm` or `npx`. Update command overrides that invoke them. The dashboard route moves from `/dashboard` to `/dashboards`, with a redirect from the old route.
