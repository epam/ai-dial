# DIAL OpenAI Adapter 0.44.0

DIAL OpenAI Adapter 0.44.0 adds OpenAI models on the Bedrock Runtime endpoint, per-upstream AWS credentials, Alibaba context caching, reasoning content, and the Azure OpenAI v1 endpoints. This page summarizes the release and its patch releases, 0.44.1 and 0.44.2, with a link to the full notes of each. It is for platform engineers who plan an adapter upgrade.

Platform release 1.48 ships DIAL OpenAI Adapter 0.44.0; see [Upgrade to DIAL 1.48](../../../8.reference/changelog/upgrade-to-1.48.md).

## 0.44.0

Released 2026-09-22. [Release notes](https://github.com/epam/ai-dial-adapter-openai/releases/tag/0.44.0)

**Added**

- OpenAI models on the Amazon Bedrock Runtime endpoint.
- Per-upstream AWS credentials and STS role assumption for Bedrock upstreams.
- Context caching for Alibaba Cloud Model Studio.
- Reasoning tokens in the `reasoning_content` field of Chat Completions responses.
- The Azure OpenAI v1 API endpoints.
- Simpler rules for where the upstream model name comes from. See [How it works](../0.index.md#how-it-works).

## Patch releases

### 0.44.1

Released 2026-10-02. [Release notes](https://github.com/epam/ai-dial-adapter-openai/releases/tag/0.44.1)

- **Fixed:** the assume-role credential cache is bounded, and the STS client is cached.

### 0.44.2

Released 2026-10-05. [Release notes](https://github.com/epam/ai-dial-adapter-openai/releases/tag/0.44.2)

- **Added:** the dated `api-version` endpoints of the Responses API.
- **Fixed:** `api-version` is optional for the Azure OpenAI v1 API; upstream error fields that clash with DIAL error parameters are preserved.
