# DIAL OpenAI Adapter 0.45.0

DIAL OpenAI Adapter 0.45.0 makes the upstream connection pool and the keep-alive timeout configurable, and moves the server to uvloop and httptools. This page summarizes the release and its patch releases, 0.45.1 and 0.45.2, with a link to the full notes of each. It is for platform engineers who plan an adapter upgrade.

## 0.45.0

Released 2026-10-14. [Release notes](https://github.com/epam/ai-dial-adapter-openai/releases/tag/0.45.0)

**Added**

- Configurable upstream connection limits: `HTTP_MAX_CONNECTIONS`, `HTTP_MAX_KEEPALIVE_CONNECTIONS`, and `HTTP_POOL_TIMEOUT`, with `503` when the pool is exhausted. See [Performance](../3.configuration.md#performance).
- `TIMEOUT_KEEP_ALIVE` for the server's keep-alive timeout.
- The server runs on uvloop and httptools.
- Extra text-to-speech configuration fields are passed to the Speech API upstream.

**Fixed**

- No warning for session tag paths into unset optional UserInfo fields.

**Changed**

- Faster OpenTelemetry Protobuf export, and upgrades of `aidial-adapter-anthropic` to 0.18.0 and `aidial-sdk` to 0.45.0.

## Patch releases
