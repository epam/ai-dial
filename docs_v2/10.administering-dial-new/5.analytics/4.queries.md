# Queries [Preview]

Navigate to **Analytics → Queries** to author, save, and run read-only queries against any analytics
[table](2.tables.md) — source, enrichment, or rollup. Results render as a table or a chart, and queries
can be saved for reuse and sharing.

## Queries grid

| Column | Description |
|--------|-------------|
| **Name** | Query name. |
| **Description** | Free-text summary. |
| **Source** | The table(s) the query reads. |
| **Tag** | Optional label for grouping and filtering. |
| **Visibility** | **Personal** (only you) or **Common** (shared; writable only by a full admin). |
| **Editor** | How the query is authored: **Builder**, **JSON**, or **SQL** (derived from the saved body). |
| **Saved by** | The query's owner. |
| **Updated time** | Timestamp of the last change. |

Row actions: open in a new tab, **Duplicate**, **Edit**, and **Delete** (Edit and Delete are disabled on
Common queries for non-admins). Use **Create** (top-right) to start a new query.

## The query workbench

Opening or creating a query shows the workbench. The header has a **Source** selector, a **Time Period**
selector, and **Edit**, **Copy**, and **Run** actions.

### Authoring surfaces

The editor offers four tabs for the same query:

| Tab | Description |
|-----|-------------|
| **Builder** | A visual form: pick fields, filters, grouping, aggregates, sort, and paging. |
| **JSON** | The structured query as JSON. |
| **SQL** | Raw SQL, with field/entity/keyword/function auto-completion. |
| **AI** | A natural-language assistant that drafts a query from a prompt. Shown only when `DIAL_QUERY_ASSISTANT_DEPLOYMENT` is configured. |

A query runs in one of two modes: **row** (return matching rows) or **aggregate** (group and compute
measures).

### Results

Click **Run** to execute the query. Results render in the left pane, switchable between:

- **Table** — the result rows.
- **Chart** — a **bar**, **line**, **pie**, or **scatter** chart, mapping result columns to axes.

## Save a query

When saving, provide:

| Field | Required | Description |
|-------|----------|-------------|
| **Name** | Yes | Query name. |
| **Description** | No | Free-text summary. |
| **Tag** | No | Label for grouping and filtering. |
| **Scope** | Yes | **Personal** or **Common**. Common queries are writable only by full admins. |

The saved query records the query body (builder/JSON/SQL), the time window, and the result view
(table or chart). The **Source** is derived from the body.
