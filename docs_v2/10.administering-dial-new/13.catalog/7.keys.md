# Catalog — Keys

The Catalog Keys page shows platform-level API key definitions as they exist in DIAL Core.
This is a read-only browse view — to configure API keys, use
[Access management — Keys](../6.access-management/2.keys.md).

## Keys grid

Navigate to **Catalog > Keys** to see all platform API key definitions.

<!-- SCREENSHOT NEEDED: catalog keys grid -->

| Column | Description |
|--------|-------------|
| **Display Name** | Key name displayed on the UI. |
| **ID** | Unique identifier of the API key. |
| **Description** | Description of the API key. |
| **Creation Time** | Timestamp when the key was created. |
| **Updated Time** | Timestamp of the last update. |

## Key detail view

Click any key row to open its detail view showing the key's properties, roles, and usage
limits.

**Tip**
> Use the configuration toggle (top-right) to view the raw JSON configuration.
