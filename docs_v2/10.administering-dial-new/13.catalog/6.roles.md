# Catalog — Roles

The Catalog Roles page shows platform-level role definitions as they exist in DIAL Core.
This is a read-only browse view — to configure roles, use
[Access management — Roles](../6.access-management/1.roles.md).

## Roles grid

Navigate to **Catalog > Roles** to see all platform role definitions.

<!-- SCREENSHOT NEEDED: catalog roles grid -->

| Column | Description |
|--------|-------------|
| **Display Name** | Role name displayed on the UI. |
| **ID** | Unique identifier of the role. |
| **Description** | Description of the role. |
| **Creation Time** | Timestamp when the role was created. |
| **Updated Time** | Timestamp of the last update. |

## Role detail view

Click any role row to open its detail view showing the role's properties, entities, and
limit configuration.

**Tip**
> Use the configuration toggle (top-right) to view the raw JSON configuration.
