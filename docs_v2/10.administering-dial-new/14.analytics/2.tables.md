# Tables [Preview]

Navigate to **Analytics → Tables** for the catalog of analytics tables — the data that pipelines,
queries, dashboards, and sessions all read and write. There are two kinds:

- **Source** tables — landing tables for raw data (for example the hop log `dial_usage_log`).
- **Enrichment** tables — derived tables, keyed on a *grain* of a source table, populated by an
  enrichment [pipeline](3.pipelines.md) (for example `session_insights`).

## Tables grid

| Column | Description |
|--------|-------------|
| **Name** | Table identifier (snake_case). |
| **Type** | `source` or `enrichment`. |
| **Source table** | For an enrichment table, the source table it derives from. |
| **Description** | Free-text summary. |
| **Columns** | Number of columns in the table. |
| **Status** | `pending` (schema not yet defined), `active` (schema materialized, table in use), or `failed`. |
| **System** | Marked **System** for built-in tables; blank for user-created tables. |

Use **Create source** and **Create enrichment** (top-right) to add tables.

## Detail view

Click any table to open its detail view. The header shows status badges and these actions:
**Manage access**, **Add columns**, **Connect**, **Delete table**, and a **JSON Editor** toggle.
The tab strip is **Properties** and **Audit**.

### Properties

The Properties tab shows the table's key metadata and its column schema.

Metadata:

| Field | Description |
|-------|-------------|
| **Source** / **Grain key** | *(Enrichment tables)* The source table and the column that defines one row of enrichment (for example `chat_id`). |
| **Ordering key** | *(Source tables)* Column that orders rows within the table. |
| **Partition column** / **Granularity** | *(Source tables)* Column the table is partitioned on, and the partition granularity (`day`, `month`, or `year`). |
| **Identity column** | *(Source tables)* Column that identifies a logical row for deduplication. |
| **Version column** | Column used to pick the latest version of a row. |

Columns grid:

| Column | Description |
|--------|-------------|
| **Name** | Column identifier (snake_case, max 64 chars). A **Sensitive** flag marks columns that hold sensitive data. |
| **Type** | Data type: `uuid`, `string`, `enum`, `integer`, `long`, `decimal`, `boolean`, `date`, `timestamp`, `object`, or `array`. |
| **Tag** | Semantic role of the column (for example `identity`, `insight`, `provenance`). |
| **Display name** | Human-readable label shown in other screens. |
| **Description** | What the column holds. |
| **Nullable** | Whether the column may be empty. |

### Audit

The Audit tab records configuration changes to the table (available when the Admin API is enabled).

### Manage access

The **Manage access** panel controls role-based access to the table: which roles may **write** rows and
which may **modify** the table.

### Connect

The **Connect** panel provides read/write connection snippets for reading from or writing to the table
from outside DIAL Admin. For enrichment tables the write half is hidden — their rows come from the
enrichment pipeline.

## Create a table

1. Click **Create source** or **Create enrichment**.
2. Provide the fields:

    | Field | Required | Description |
    |-------|----------|-------------|
    | **Name** | Yes | Snake_case table identifier. |
    | **Description** | No | Free-text summary. |
    | **Source** | Enrichment only | The source table this enrichment derives from. |
    | **Write mode** | Source only | How rows are written: **append** (insert every row) or **upsert by key** (replace rows with the same key). Chosen at creation and immutable afterward. |

3. The table is created in **pending** status. Open it and **define its schema** (columns, keys) in the
   draft schema editor — in form or JSON mode. Saving the schema **materializes** the table and moves it
   to **active**.

**Note**
> A table's schema can be edited only while it is **pending** or **failed**. Once **active**, you can
> still add, drop, rename, or re-tag columns, but a column's `enum` value set is immutable — to widen it,
> drop and re-add the column.
