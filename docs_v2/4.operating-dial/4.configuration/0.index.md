# Configuration overview

This section provides configuration references for all DIAL components. It is intended for DevOps and platform engineers who deploy and operate DIAL.

:::tip
These are reference pages — they document every option. For step-by-step authentication and access-control setup (API keys, JWT, and SSO / IdP), see [Auth and access control](../5.auth-and-access-control/0.index.md).
:::

## Configuration files

DIAL uses JSON, XML, and YAML configuration files alongside environment variables. Each file has a dedicated reference page:

| File | Component | Format | Reload | Reference |
|------|-----------|--------|--------|-----------|
| `settings.json` | DIAL Core | JSON | At startup (static) | [Static settings](../../6.services/1.core/1.configuration/2.settings/0.index.md) |
| `config.json` | DIAL Core | JSON | Every 60 seconds (dynamic) | [How DIAL Core is configured](../../6.services/1.core/1.configuration/0.index.md) |
| `gflog.xml` | DIAL Core | XML | At startup | [gflog.xml](../../6.services/1.core/1.configuration/3.gflog-xml.md) |
| `realm-config.json` | Keycloak | JSON | At Keycloak startup | [realm-config.json](./2.realm-config-json.md) |
| `application.yaml` | Auth Helper | YAML | At startup | [Auth Helper](./1.auth-helper-configuration.md) |
| `docker-compose.yml` | Docker Compose | YAML | At `docker compose up` | [Docker Compose](./4.docker-compose/0.index.md) |
| `.env` | Docker Compose | Key=Value | At `docker compose up` | [.env reference](./4.docker-compose/3.env-reference.md) |
| `values.yaml` | DIAL Helm charts | YAML | At Helm install/upgrade | [DIAL Helm configuration](../../6.services/11.helm/1.configuration/0.index.md) |

The reference for [DIAL Core](../../6.services/1.core/0.index.md), [DIAL Chat](../../6.services/2.chat/0.index.md), [DIAL Chat Themes](../../6.services/3.chat-themes/0.index.md), and the [OpenAI](../../6.services/4.openai-adapter/0.index.md), [Bedrock](../../6.services/5.bedrock-adapter/0.index.md), and [Vertex AI](../../6.services/6.vertex-ai-adapter/0.index.md) adapters is in Services.
