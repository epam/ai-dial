## Partially documented

These areas are covered but have known gaps:

| Topic | What exists | What is missing |
|---|---|---|
| **Interceptors configuration** | Interceptor *registration* documented in DIAL Core dynamic settings. | SDK-side configuration for building interceptors is a developer topic, covered under Building with DIAL rather than here. |
| **OpenAI Adapter advanced features** | Env vars and basic upstream examples documented. | Detailed operational guides for: configurable models (DALL-E parameters, Responses API reasoning configuration), tokenization algorithms, and API versioning strategies. |
| **Secrets management patterns** | [Manage secrets](../7.production-readiness/3.secrets-management.md) covers Kubernetes Secrets and the Secrets Store CSI driver, with a complete Azure Key Vault example and short steps for AWS Secrets Manager and Google Secret Manager. | HashiCorp Vault integration, and complete examples for AWS Secrets Manager and Google Secret Manager. |
| **DIAL Core budgets and org units** | `spendingLimits` modes and `orgUnits.enabled` are documented in [Global settings](../../6.services/1.core/1.configuration/14.global-settings.md) and [Access](../../6.services/1.core/1.configuration/2.settings/7.access.md). | The fields of budget policies and policy assignments, and the org units API (preview). The DIAL Core documentation does not describe them yet. |
