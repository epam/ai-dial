# Operating DIAL

This section is for DevOps and platform engineers who install, configure, and run DIAL. It covers local setups with Docker Compose, cloud deployment with Helm, model connections, configuration, authentication, observability, and production hardening. It assumes you know Docker for local setups and Kubernetes for cluster deployments.

## Install DIAL

- [Local setup](1.local-setup/0.index.md) — run a complete DIAL stack on one machine with Docker Compose, connected to an application, Ollama, vLLM, Azure OpenAI, or a remote DIAL Core
- [Cloud deployment](2.cloud-deployment/0.index.md) — deploy the Helm charts to AWS, Azure, GCP, or another Kubernetes cluster, then add [Custom Apps](2.cloud-deployment/6.custom-apps-deployment.md), [Quick Apps](2.cloud-deployment/7.quick-apps-installation.md), or [DIAL Admin](2.cloud-deployment/8.admin-installation.md)
