# Evaluators [Preview]

Evaluators are automated scoring functions that evaluate conversations against defined criteria.
They run within [pipelines](2.pipelines.md) to produce quality metrics that are stored in
[tables](1.tables.md).

## Evaluators grid

Navigate to **Analytics > Evaluators** to see all evaluators.

<!-- SCREENSHOT NEEDED: analytics evaluators grid -->

| Column | Description |
|--------|-------------|
| **Name** | Display name of the evaluator. |
| **Latest Version** | Most recent version of the evaluator. |
| **Registered At** | Timestamp when the evaluator was first registered. |
| **Used By** | Number of pipelines that reference this evaluator. |
| **Actions** | Per-row actions: **Open in a new tab**. |

To create an evaluator, click **Create**.

## Evaluator detail view

Click any evaluator row to open its detail view.

### Properties

| Field | Description |
|-------|-------------|
| **Name** | Display name of the evaluator. |
| **Version** | Current version. Use the version switcher to navigate between versions. |
| **Description** | Free-text summary of what the evaluator measures. |

### Parameters editor

Define the input parameters the evaluator accepts when invoked by a pipeline.

### Outputs editor

Define the output fields the evaluator produces (e.g. scores, labels, explanations).

### Linked pipelines

Grid showing which pipelines reference this evaluator, with links to each pipeline's detail view.
