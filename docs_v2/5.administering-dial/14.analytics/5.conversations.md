# Conversations [Preview]

The Conversations section lets you browse and inspect conversation traces across all users and
deployments. Use it to review message history, model responses, token usage, timing data, and
user feedback for individual conversations.

**Note**
> This sub-section requires both `ANALYTICS_ENABLED` and `ANALYTICS_CONVERSATIONS_ENABLED`
> environment variables to be set to `true`.

## Conversations list

Navigate to **Analytics > Conversations** to see conversation traces.

<!-- SCREENSHOT NEEDED: analytics conversations list -->

### Toolbar controls

| Control | Description |
|---------|-------------|
| **Time period** | Filter conversations by time range. |
| **Time range** | Fine-grained time range selector. |
| **Search** | Search conversations by content or metadata. |
| **Feedback filter** | Filter by user feedback (positive, negative, or all). |

### Conversation list

The list shows a summary of each conversation with:

- Summary header with key metadata
- Provenance line (user, deployment, timestamp)
- Scrollable list with server-side pagination

### Rating summary

Aggregated rating counts are displayed in the list header, showing the distribution of user
feedback across conversations.

## Conversation detail view

Click any conversation to open its detail view.

<!-- SCREENSHOT NEEDED: analytics conversation detail -->

The detail view shows:

- Full message history with user messages and assistant responses
- Token usage per message
- Timing data (latency, time to first token)
- User feedback/ratings for individual messages
- Enrichment data and evaluation scores (when pipelines have processed the conversation)
