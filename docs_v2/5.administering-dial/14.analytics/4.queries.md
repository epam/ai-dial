# Queries [Preview]

The Queries section lets you build and run SQL-like queries against analytics data. Queries can be
saved for reuse and shared with other administrators.

## Queries list

Navigate to **Analytics > Queries** to see all saved queries.

<!-- SCREENSHOT NEEDED: analytics queries list -->

| Column | Description |
|--------|-------------|
| **Name** | Display name of the query. |
| **Description** | Free-text summary of what the query retrieves. |
| **Tag** | Category tag for organizing queries. |
| **Scope** | Access scope: **Personal** (visible only to you) or **Common** (shared with all administrators). |
| **Actions** | Per-row actions: **Open in a new tab**, **Duplicate**, **Edit**, **Delete**. |

To create a query, click **Create**.

## Query builder

Click any query to open the **Query Builder** — a visual editor for composing and running queries.

### Source selector

Select the analytics [table](1.tables.md) to query from.

### Expression editor

Build query expressions using:

- **Visual mode**: drag-and-drop query composition with field pickers, aggregation selectors, and
  filter builders.
- **JSONata mode**: write raw JSONata expressions for complex transformations and computed fields.
- **Composite SQL**: combine multiple SQL-like statements with scalar functions.

### Result preview

Run the query and view results in a grid below the editor. Results can be exported for further
analysis.
