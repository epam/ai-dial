# Tables [Preview]

Analytics tables store the enriched data that [pipelines](2.pipelines.md) produce. Each table has a
defined schema with typed columns, access controls, and a write mode that determines how data is
ingested.

## Tables grid

Navigate to **Analytics > Tables** to see all analytics tables.

<!-- SCREENSHOT NEEDED: analytics tables grid -->

| Column | Description |
|--------|-------------|
| **Name** | Display name of the table. |
| **Status** | Current status of the table. |
| **Creation date** | Timestamp when the table was created. |
| **Actions** | Per-row actions: **Open in a new tab**, **Delete**. |

To create a table, click **Create**.

## Table detail view

Click any table row to open its detail view.

### Properties

| Field | Description |
|-------|-------------|
| **Name** | Display name of the table. |
| **Description** | Free-text summary of the table's purpose. |
| **Write mode** | How data is written to the table (e.g. append, overwrite). |

### Schema editor

Define the columns that make up the table. Each column has a name, data type (including enum
types), and optional description. The schema determines what data pipelines can write to this
table.

### Access panel

Configure who can read from and write to this table.

### Connect panel

Shows connection details for querying this table from external tools.

### Audit

Track configuration changes to this table.

### JSON editor

Advanced users can view and edit the table's raw JSON configuration.
