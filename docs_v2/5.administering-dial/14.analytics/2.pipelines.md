# Pipelines [Preview]

Pipelines orchestrate multi-step data processing workflows that combine enrichment rules,
[evaluators](3.evaluators.md), and other transformations. Pipelines process conversation data and
produce enriched output that is stored in [tables](1.tables.md).

## Pipelines grid

Navigate to **Analytics > Pipelines** to see all pipelines.

<!-- SCREENSHOT NEEDED: analytics pipelines grid -->

| Column | Description |
|--------|-------------|
| **Name** | Display name of the pipeline. |
| **Kind** | Pipeline type: **Aggregate** or **Enrich**. |
| **Evaluator** | The evaluator used by this pipeline (if applicable). |
| **Trigger** | What triggers the pipeline to run. |
| **Enabled** | Whether the pipeline is currently active. |
| **Created** | Timestamp when the pipeline was created. |
| **Actions** | Per-row actions: **Open in a new tab**, **Delete**. |

To create a pipeline, click **Create**.

## Pipeline detail view

Click any pipeline row to open its detail view.

### Configuration

Configure the pipeline's processing steps, trigger conditions, and output destination (target
table).

### Audit

Track configuration changes to this pipeline, following the same pattern as
[Activity and rollback](../8.audit/1.activity-and-rollback.md).
