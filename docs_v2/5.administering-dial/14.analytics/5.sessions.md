# Sessions [Preview]

Navigate to **Analytics → Sessions** for a conversation-observability view. Each row is one **session**
(a chat conversation). The screen is read-only — it is built by querying the hop log
(`dial_usage_log`), the `sessions` rollup, the `session_insights` enrichment, and `response_ratings`
live, so there is nothing to create or edit here.

**Note**
> Sessions is a [Preview] feature, shown when `ANALYTICS_ENABLED` and `ANALYTICS_SESSIONS_ENABLED` are
> set. The **Insights** it displays come from an enrichment [pipeline](3.pipelines.md) (an *evaluator*);
> sessions that pipeline has not processed show no insights.

## Summary tiles

The top of the screen summarizes the selected window: **Sessions**, **Rated**, number **With 👎**, and
**Cost**.

## Controls

| Control | Description |
|---------|-------------|
| **Search** | Filter sessions by text across sessions and projects. |
| **Time Period** | Date range for the list. |
| **Feedback** | Filter by feedback: **All**, 👍 (positive), 👎 (negative), or **Rated**. |
| **Columns** | Show or hide columns. |

## Sessions grid

Columns are grouped into bands and built dynamically from the live schema, so insight columns added to
the enrichment appear automatically:

| Band | Columns |
|------|---------|
| **Identity** | Session (title + id). |
| **Activity** | Last activity time. |
| **Attribution** | Project, User. |
| **Cost** | Cost. |
| **Ratings** | 👍 and 👎 counts. |

Insight columns (title, summary, sentiment, topic, language, resolution status, and others) come from the
`session_insights` enrichment and can be shown as additional columns.

## Session detail

Click a session to open its detail view — a read-only set of panels plus a trace.

Header: session **Id**, **Project**, **Turns**, **Duration**, and **Last activity**.

| Panel | Description |
|-------|-------------|
| **Insights** | LLM-derived insights from the `session_insights` enrichment (title, summary, sentiment, topic, and so on). Shows **not evaluated** when the session has no insight row yet, or **unavailable** when the enrichment is not provisioned. |
| **Usage** | Tokens in/out, total tokens, cost, duration, and average duration. |
| **Feedback** | Ratings and comments from `response_ratings`. |
| **Metadata** | Session id, user, project, start time, turn count, trace id, and deployments. |

### Traces

Below the panels, **Traces in this session** lists the session's root spans (one card per root call).
Each card shows the deployment, status, timing, token and cost totals, and tags such as the number of
MCP and LLM calls. Expand a card to see its spans, and open the **inspector** to read the request and
response bodies for each hop.
