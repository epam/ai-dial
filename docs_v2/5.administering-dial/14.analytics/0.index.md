# Analytics [Preview]

The **Analytics** section of DIAL Admin provides tools for analyzing conversation data, building
custom queries, and managing data enrichment pipelines. Use it to gain insights into how models
and applications are being used across your DIAL deployment.

**Note**
> Analytics is a [Preview] feature. It is gated by the `ANALYTICS_ENABLED` environment variable
> and may change significantly before general availability.

## Sub-sections

| Sub-section | Description |
|-------------|-------------|
| [Tables](1.tables.md) | Manage analytics data tables — configure columns, schemas, write modes, and access controls for the data that pipelines produce. |
| [Pipelines](2.pipelines.md) | Orchestrate multi-step data processing workflows that combine enrichment rules, evaluators, and transformations. |
| [Evaluators](3.evaluators.md) | Configure automated scoring functions that evaluate conversations against defined criteria within pipelines. |
| [Queries](4.queries.md) | Build and run SQL-like queries against analytics data. Save and share queries for reuse. |
| [Conversations](5.conversations.md) | Browse and inspect conversation traces across all users and deployments. |

## Configuration

To enable Analytics, set the following environment variables on the Admin Frontend:

| Variable | Description |
|----------|-------------|
| `ANALYTICS_ENABLED` | Set to `true` to enable the Analytics section in the Admin Panel sidebar. Required for all Analytics sub-sections. |
| `ANALYTICS_CONVERSATIONS_ENABLED` | Set to `true` to enable the Conversations sub-section. Requires `ANALYTICS_ENABLED`. |

## How the sections connect

The typical analytics workflow is:

1. **Define evaluators** — create scoring functions that measure conversation quality.
2. **Build pipelines** — combine enrichment rules and evaluators into processing workflows
   that run against conversation data.
3. **Configure tables** — define the schema and storage for pipeline output.
4. **Query results** — use the query builder to analyze enriched data.
5. **Browse conversations** — inspect individual conversations with their enrichment data
   and evaluation scores.
