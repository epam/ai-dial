# Metrics

Metrics are reusable scoring functions that evaluate model or application responses. Each metric
defines what it measures (for example, faithfulness, relevance, or factual accuracy) and how its
inputs are bound to test-case data. Metrics are created once and then attached to one or more test
suites.

## Metrics grid

Open **Evaluation > Metrics** to see all registered metrics.

<!-- SCREENSHOT NEEDED: metrics list grid -->

| Column | Description |
|--------|-------------|
| **Name** | Display name of the metric. |
| **Description** | Brief summary of what the metric measures. |
| **Creation date** | Timestamp when the metric was created. |

Use the search bar to filter metrics by name.

## Metric detail view

Click any metric row to open its detail view. The detail view shows the metric's configuration,
including its input schema, output schema, and binding parameters.
