# Catalog — Interceptors

The Catalog Interceptors page shows platform-level interceptor definitions as they exist in DIAL
Core. This is a read-only browse view — to configure interceptors, use
[Entities — Interceptors](../2.entities/4.interceptors.md).

## Interceptors grid

Navigate to **Catalog > Interceptors** to see all platform interceptor definitions.

<!-- SCREENSHOT NEEDED: catalog interceptors grid -->

| Column | Description |
|--------|-------------|
| **Display Name** | Interceptor name displayed on the UI. |
| **ID** | Unique identifier of the interceptor. |
| **Description** | Description of the interceptor. |
| **Source Type** | Source type: Interceptor Template, Interceptor Deployment, or External Endpoint. |
| **Source** | Identifier of the interceptor source. |
| **Status** | Current status: local or global. |
| **Topics** | Semantic labels associated with the interceptor. |
| **Creation Time** | Timestamp when the interceptor was created. |
| **Updated Time** | Timestamp of the last update. |

## Interceptor detail view

Click any interceptor row to open its detail view showing properties, parameter scheme, entities,
and application runners.

**Tip**
> Use the configuration toggle (top-right) to view the raw JSON configuration.
