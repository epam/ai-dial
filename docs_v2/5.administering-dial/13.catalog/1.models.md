# Catalog — Models

The Catalog Models page shows platform-level model definitions as they exist in DIAL Core. This is
a read-only browse view — to configure model deployments, use
[Entities — Models](../2.entities/1.models.md).

## Models grid

Navigate to **Catalog > Models** to see all platform model definitions.

<!-- SCREENSHOT NEEDED: catalog models grid -->

| Column | Description |
|--------|-------------|
| **Display Name** | Model name displayed on the UI. |
| **ID** | Unique identifier of the model in DIAL Core configuration. |
| **Description** | Description of the model. |
| **Source Type** | Source type: Adapter, External Endpoint, or Model Serving. |
| **Source** | Identifier of the model source. |
| **Status** | Current status of the model. |
| **Topics** | Semantic labels associated with the model. |
| **Creation Time** | Timestamp when the model was created. |
| **Updated Time** | Timestamp of the last update. |

## Model detail view

Click any model row to open its detail view. The detail view shows the model's properties,
features, interfaces, and roles configuration in a read-only format.

The detail view includes an **Audit** tab that shows the change history for this specific model.

**Tip**
> Use the configuration toggle (top-right) to view the raw JSON configuration that DIAL Core
> consumes for this model.
