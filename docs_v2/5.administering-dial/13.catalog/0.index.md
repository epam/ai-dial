# Catalog [Preview]

The **Catalog** is a top-level menu group in DIAL Admin that provides a unified browse-and-manage
view for platform-level entities. While [Entities](../2.entities/1.models.md) focuses on deployment
configuration and [Assets](../4.assets/0.index.md) manages user-published content in the Public folder, the
Catalog exposes the platform-level definitions that DIAL Core consumes — the same data, presented
through a consistent browse interface.

**Note**
> The Catalog menu group is a [Preview] feature. To hide it, set the `DISABLE_MENU_ITEMS`
> environment variable to include `catalog`.

## What appears in the Catalog

Each sub-page corresponds to a platform entity type:

| Sub-page | Description | Related configuration page |
|----------|-------------|--------------------------|
| [Models](1.models.md) | Platform model definitions | [Entities — Models](../2.entities/1.models.md) |
| [Interceptors](2.interceptors.md) | Platform interceptor definitions | [Entities — Interceptors](../2.entities/4.interceptors.md) |
| [Translators](3.translators.md) | API translator definitions [Preview] | [Platform Models](1.models.md) |
| [Routes](4.routes.md) | Platform route definitions | [Entities — Routes](../2.entities/5.routes.md) |
| [App Runners](5.app-runners.md) | Platform application runner definitions | [Builders](../3.builders/1.application-runners.md) |
| [Roles](6.roles.md) | Platform role definitions | [Access management — Roles](../6.access-management/1.roles.md) |
| [Keys](7.keys.md) | Platform API key definitions | [Access management — Keys](../6.access-management/2.keys.md) |

## Common patterns

All Catalog pages follow the same layout:

- **Grid view**: A list of platform-level entities with sortable columns, search, and filtering.
- **Detail view**: Click any row to open a detail view showing the entity's properties and
  configuration. Detail views include a read-only configuration toggle that shows the underlying
  JSON consumed by DIAL Core.
- **Audit tab**: Entity detail views include an Audit tab for tracking configuration changes.

Catalog entity views are read-only reflections of the configuration in DIAL Core. To modify an
entity, use its corresponding configuration page (linked in the table above).
