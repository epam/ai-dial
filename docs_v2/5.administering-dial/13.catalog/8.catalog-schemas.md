# Catalog Schemas

In catalog schemas you can declare what metadata a catalog entity type exposes and how the DIAL Catalog renders it for specific types of entities.

## How to use Catalog Schemas

Catalog Schemas are configured through the **Catalog metadata** section in models, applications, toolsets, skills and interceptors (if available) properties.

## Catalog Schemas grid

Navigate to **Catalog Schemas** to see all Catalog Schemas definitions.

| Column | Description |
|--------|-------------|
| **Name** | Translator name displayed on the UI. |
| **Author** | The user who created the Catalog Schema. |
| **Created Time** | Timestamp when the Catalog Schema was created. |
| **Updated Time** | Timestamp of the last update. |

## Catalog Schema detail view

Click any Catalog Schema row to open its detail view showing properties and
parameters.

**Tip**
> Use the configuration toggle (top-right) to view the raw JSON configuration.


### Properties

In this section, you can define basic properties of a schema.

**Tip**
> Name, ID are immutable for created schemas in the platform folder. Only Entity Type is mutable for schemas in the file folder.

| Property | Description |
|--------|-------------|
| **Name** | Catalog schema name rendered in Admin UI. |
| **ID** | Catalog schema unique identifier. |
| **Entity type** | Type of entity the schema is associated with: model, agent, toolset, interceptor. |
| **Display Name** | Human-readable name of the catalog entity type. |
| **Default locale** | BCP-47 locale used as the fallback for every localized field. Optional; defaults to **en** when omitted |

![Catalog Schemas properties](../img/catalog-schema-properties.png)

### Parameters

In this section you can define fields that will be rendered in the DIAL Catalog for entities associated with the schema.

| Filed | Description |
|--------|-------------|
| **Name** | Filed name |
| **Title** | Field title |
| **Description** | Description of the field |
| **Data Type** | Data type of the field |
| **Requirement** | Whether the field is required or not |
| **Order** | Order of the field within its section |
| **Tab** | Tab the field renders in, e.g. Summary, About, Overview, Pricing, API |
| **Section** | Section within the tab, e.g. Capabilities, Specification |
| **Widget** | Rendering hint for the generic catalog renderer |
| **Localized** | Marks the field value as a BCP-47 locale-to-value map |

![Catalog Schemas parameters](../img/catalog-schema-parameters.png)
