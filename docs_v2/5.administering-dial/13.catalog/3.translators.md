# Catalog — Translators [Preview]

The Catalog Translators page shows platform-level API translator definitions. Translators enable
a model to be accessed through an API protocol it does not natively support — for example, making
an Anthropic Messages model available through the OpenAI Chat Completions interface.

Translators are configured through the Interfaces section on [Platform Models](1.models.md), where
each interface can operate in Proxy or Translator mode.

## Translators grid

Navigate to **Catalog > Translators** to see all platform translator definitions.

<!-- SCREENSHOT NEEDED: catalog translators grid -->

| Column | Description |
|--------|-------------|
| **Display Name** | Translator name displayed on the UI. |
| **ID** | Unique identifier of the translator. |
| **Description** | Description of the translator. |
| **Creation Time** | Timestamp when the translator was created. |
| **Updated Time** | Timestamp of the last update. |

## Translator detail view

Click any translator row to open its detail view showing the translator's properties and
configuration.

**Tip**
> Use the configuration toggle (top-right) to view the raw JSON configuration.
