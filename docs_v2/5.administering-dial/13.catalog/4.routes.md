# Catalog — Routes

The Catalog Routes page shows platform-level route definitions as they exist in DIAL Core.
This is a read-only browse view — to configure routes, use
[Entities — Routes](../2.entities/5.routes.md).

## Routes grid

Navigate to **Catalog > Routes** to see all platform route definitions.

<!-- SCREENSHOT NEEDED: catalog routes grid -->

| Column | Description |
|--------|-------------|
| **Display Name** | Route name displayed on the UI. |
| **ID** | Unique identifier of the route. |
| **Description** | Description of the route. |
| **Creation Time** | Timestamp when the route was created. |
| **Updated Time** | Timestamp of the last update. |

## Route detail view

Click any route row to open its detail view showing the route's properties and configuration.

**Tip**
> Use the configuration toggle (top-right) to view the raw JSON configuration.
