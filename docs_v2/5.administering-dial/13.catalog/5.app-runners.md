# Catalog — App Runners

The Catalog App Runners page shows platform-level application runner definitions as they exist in
DIAL Core. This is a read-only browse view — to configure application runners, use
[Builders — Application Runners](../3.builders.md#application-runners).

## App Runners grid

Navigate to **Catalog > App Runners** to see all platform application runner definitions.

<!-- SCREENSHOT NEEDED: catalog app runners grid -->

| Column | Description |
|--------|-------------|
| **Display Name** | Application runner name displayed on the UI. |
| **ID** | Unique identifier of the application runner. |
| **Description** | Description of the application runner. |
| **Creation Time** | Timestamp when the application runner was created. |
| **Updated Time** | Timestamp of the last update. |

## App Runner detail view

Click any app runner row to open its detail view showing the runner's properties, parameters,
features, and interceptor configuration.

**Tip**
> Use the configuration toggle (top-right) to view the raw JSON configuration.
