# Connecting to DIAL

This section shows how to connect the tools your organization already uses to DIAL, so they reach DIAL's models, applications, and Toolsets through one governed layer. It is for developers who connect an existing tool to a running DIAL deployment. Each guide lists the access it needs, usually a DIAL host and an API key.

## Agentic tools

Coding agents and desktop assistants, such as Claude Code, Codex, and GitHub Copilot, that use DIAL as their model backend. DIAL applies its roles, quotas, and cost tracking to every turn.

[Go to Agentic tools](1.agentic-tools/0.index.md)

## Chatbot integrations

AI in messaging platforms such as Microsoft Teams and Microsoft Copilot, so users reach DIAL from where they already chat.

[Go to Chatbot integrations](2.chatbot-integrations/0.index.md)

## Productivity add-ins

AI in desktop and productivity tools, such as spreadsheet functions that call DIAL.

[Go to Productivity add-ins](3.productivity-add-ins/0.index.md)

## Workflow automation

DIAL as a node in automation pipelines, callable from low-code workflow builders.

[Go to Workflow automation](4.workflow-automation/0.index.md)

To build something that runs on DIAL itself, such as an application, a Toolset, an interceptor, or an adapter, see [Building with DIAL](../4.building-with-dial/0.index.md).
