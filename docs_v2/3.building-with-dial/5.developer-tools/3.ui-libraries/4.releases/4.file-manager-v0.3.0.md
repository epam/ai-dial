# DIAL File Manager 0.3.0

File Manager 0.3.0 rebuilds the layout to the 2.0 design, moves the storage tabs into the folders panel, and adds a Sort menu and a keyboard-accessible folders tree. This page summarizes the release and its patch releases, 0.3.1 to 0.3.5, for frontend developers who plan an upgrade. DIAL Chat 1.2.22 pins 0.3.5, and DIAL Admin Frontend 0.22.5 and DIAL Quick Apps Frontend 0.3.1 depend on 0.3.x.

## 0.3.0

Released 2026-10-08. [Release notes](https://github.com/epam/ai-dial-react-file-manager/releases/tag/0.3.0)

**Breaking**

- The `@epam/ai-dial-ui-kit` peer range is raised from `^0.14.0` to `^0.15.0`.
- The storage tabs move from the toolbar into the folders panel as `FilterChips`. Move `toolbarOptions.tabs`, `activeTab`, and `onTabChange` to `treeOptions`, pass items as `{ value, label }`, and type `activeTab` as `DialFileManagerTabs`.
- `DialFileManagerTabs.All` is added as the first enum member, for a combined My files, Shared, and Organization view. `Record<DialFileManagerTabs, …>` literals need an `all` key.
- The folders panel is fixed at 360px and no longer resizes or collapses, so `treeOptions.width` and the built-in "collapse all" button are removed.
- The bulk actions bar floats over the bottom of the grid. `bulkActionsToolbarOptions.getSelectionLabel` returns only the wording, because the bar draws the count as a badge.
- The breadcrumbs are the 2.0 `Breadcrumbs`. In `navigationPanelOptions`, rename `labelClassName` to `itemClassName` and drop `onBeforeNavigate`.
- `managerLabel`, `toolbarOptions.hiddenFilesSwitcherLabel`, `navigationPanelOptions.isCompactView`, and `backButtonLabel` are removed, and `navigationPanelOptions` accepts only the search props it forwards.
- `gridOptions.wrapperBorder` is removed; restyle the grid panel through `gridOptions.containerClassName`.

**Added**

- The layout follows the 2.0 design: the hidden-files switch and the Add button sit in the content header, and the search field spans the head of the grid card.
- `DialFileManagerSortDropdown`, a Sort menu configured through `sortOptions`. Rows now default to folders first, then name ascending; `sortOptions={{ sortable: false }}` keeps the source order.
- `DialFoldersTree` is a keyboard-accessible ARIA tree with `ariaLabel`, `autoFocus`, and `onEscape`. The old `aria-label` values are gone, so update test selectors that used them.
- The folders tree and empty states follow the 2.0 design, and `searchEmptyStateTitle` sets the no-results title.
- The delete confirmation follows the DIAL delete design, with `deleteConfirmationOptions.closeLabel`. `titleRenderer` and `contentRenderer` receive the items as a second argument.
- Layout class hooks: `contentClassName`, `contentHeaderClassName`, and `gridOptions.containerClassName`.
- `skipForbiddenSymbolsCheckForActions` keeps actions for items whose names match `forbiddenSymbolsRegExp`.
- `gridOptions.additionalGridOptions` can set `rowHeight` and `headerHeight`.

**Fixed**

- A file found by search can be selected even when its folder is not loaded in the tree.
- In compact view, several roots, such as the `All` tab, open on a list of the roots.
- Delete is drawn in the danger color and moves to the end of the context menus.
- The Add and Sort menus open at their design widths.
- The Copy and Move destination popup matches the design.

**Other**

- `classnames` is dropped from `dependencies` in favor of the UI Kit's `mergeClasses`.
- Security-related upgrades of development dependencies. None of them reach the consumer runtime.
