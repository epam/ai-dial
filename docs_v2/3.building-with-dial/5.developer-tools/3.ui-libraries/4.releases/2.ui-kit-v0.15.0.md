# DIAL UI Kit 0.15.0

UI Kit 0.15.0 removes the legacy theme variable fallbacks, adds stable public class names and an overlay stacking token, and adds a set of 2.0 components. This page summarizes the release and its patch releases, 0.15.1 to 0.15.4, for frontend developers who plan an upgrade. DIAL Chat 1.2.22 and DIAL Quick Apps Frontend 0.3.1 depend on `^0.15.4`, and DIAL Admin Frontend 0.22.5 pins 0.15.3.

## 0.15.0

Released 2026-10-08. [Release notes](https://github.com/epam/ai-dial-ui-kit/releases/tag/0.15.0)

**Breaking**

- The legacy theme variable fallbacks are removed. A theme that still sets `--bg-control-neutral-hover`, `--stroke-focus-black`, or `--bg-control-accent-gradient-*` gets the kit's default color; rename them to `--bg-control-neutral-hover-muted`, `--stroke-focus`, and `--bg-gradient-*`. See the [migration guide](https://github.com/epam/ai-dial-ui-kit/blob/0.15.0/migration-guides/0.15.0/legacy-theme-variable-fallbacks-removal.md).
- `Slider` (2.0) is redrawn with a 12px accent thumb over an accent-tint track. The props are unchanged, so type checking does not flag it. See the [migration guide](https://github.com/epam/ai-dial-ui-kit/blob/0.15.0/migration-guides/0.15.0/slider-redesign.md).

**Added**

- `SchemaRenderer` (2.0), the JSON Schema form built from 2.0 controls. It keeps the 1.0 props except `jsonEditorTheme`.
- 2.0 components: `AutocompleteTagInput`, `Breadcrumbs`, `FilterChips`, `TransferQueue`, `BottomSheet`, `SideDrawer`, `Avatar`, `Badge`, `EntityIdentity` with the new `EntityType` enum, and `StarterButton`.
- The file-manager row pieces `FileIcon`, `FileName`, `FolderName`, and `SharedEntityIndicator` (2.0).
- Public class names: every 2.0 component stamps a stable class from the exported `DIAL_KIT_CLASS` record on the element that draws it.
- The `--z-overlay` stacking token, which drives the `z-popup`, `z-floating`, `z-interactive-tooltip`, and `z-tooltip` layers and defaults to 52.
- `Dropdown` `listStyle` and `Popup` `overlayStyle` (2.0), inline styles on the portalled panel and backdrop.
- `Slider` (2.0): `showTooltip`, `showTicks`, `leftContent`, `rightContent`, and `showValueInput`.
- `Tabs` (2.0): `TabOrientation.Vertical`, `tabListClassName`, and the `dial-kit-tab-selected` class.
- `InteractiveTooltip` (2.0): `trigger={InteractiveTooltipTrigger.Click}`, so the panel works on mobile.
- `Notification` (2.0): an `action` slot.
- `Select` (2.0): `collapseTagOverflow`, which folds the tags that do not fit into a `+N` tag.
- `InlineSelect` (2.0): `triggerClassName`, `triggerLabelClassName`, `onOpenChange`, a controlled `open`, and `listStyle`.
- `ButtonDropdown` (2.0): `listClassName` and `matchReferenceWidth` through `dropdownProps`.
- `Accordion` (2.0): `caretPosition`.
- `Calendar` (2.0): `showTimezone`, with the exported `getTimezoneLabel`, and `onBlur` on the time input.
- `MarkdownEditor` and `DialMarkdownEditor`: `showDragbar={false}`.
- `Grid` (2.0) is restyled to the 2.0 design, with new `-subtle` accent tokens. The change is visual only.
- `DialSchemaRenderer`: an `additionalProperties` entry without a schema gets a type selector and JSON editing.
- `DialFileManager`: `skipForbiddenSymbolsCheckForActions`, and `rowHeight` and `headerHeight` through `additionalGridOptions`.

**Fixed**

- A disabled `Button` or `IconButton` (2.0) with a tooltip renders `aria-disabled="true"`, so the tooltip opens while the click is still blocked.
- `Dropdown` and `Select` submenus open from the keyboard and support arrow, `Home`, and `End` navigation.
- `Select` and `Dropdown` (2.0) rows have consistent spacing and keep their 40px height in a capped panel.
- `Select` (2.0) multi-select tags are 24px chips, so one row of tags fits the 40px field.
- `Accordion` (2.0) mirrors its caret in RTL and animates. Collapsed content now stays mounted and `inert`.
- `Input`, `Textarea`, and `RadioGroupPopupField` keep their error border on hover, and a `TagInput` holding tags stays 40px tall.
- The `MarkdownEditor` (2.0) preview uses kit tokens instead of GitHub's stylesheet, and the panes swap sides correctly in RTL.
- `InlineSelectTrigger` (2.0) merges a caller's `className` with its own classes.
- The close button of a multi-line `Notification` (2.0) stays on the first line.
- `Textarea` (2.0) no longer passes `invalid` to the DOM.
- The `Danger` variant of `ConfirmationPopup` (2.0) no longer draws a red top border.
- `DialSchemaRenderer` required-field errors quote the label.

**Other**

- Dependencies refreshed in the lockfile; the published dependency and peer ranges are unchanged.
