# Exceptions

DIAL SDK turns exceptions into Unified API error responses. Raise one of its
error classes from your application or adapter and the caller receives it with
the right status code:

```python
from aidial_sdk.exceptions import InvalidRequestError

raise InvalidRequestError("The 'format' parameter must be 'json' or 'text'.")
```

Two behaviours are worth knowing before you rely on them:

- **Anything else you raise becomes a generic 500.** A `ValueError` — or even a
  `fastapi.HTTPException` — is logged with its traceback and returned to the
  caller as `Error during processing the request`. To return a specific status
  code, raise one of the SDK's classes.
- **Failing mid-stream cannot change the status code.** Once the first chunk is
  sent the response is already `200`, so the error arrives as a chunk within the
  stream rather than as an HTTP error.

For the full reference — every error class, the response body, streaming
behaviour — see
[docs/exceptions.md](https://github.com/epam/ai-dial-sdk/blob/development/docs/exceptions.md)
in the DIAL SDK repository.
