# Telemetry

Applications and adapters built on DIAL SDK emit OpenTelemetry traces, metrics,
and logs. The SDK defines no signals of its own — what you get comes from
instrumentation it installs on FastAPI, the HTTP clients, and the host process.

Enabling it takes two things: the optional extra, and a `TelemetryConfig`.

```bash
pip install "aidial-sdk[telemetry]"
```

```python
from aidial_sdk import DIALApp
from aidial_sdk.telemetry.types import TelemetryConfig

app = DIALApp(telemetry_config=TelemetryConfig(service_name="my-app"))
```

On its own that does nothing. Each signal switches on only when its exporter
variable is set — `OTEL_TRACES_EXPORTER`, `OTEL_METRICS_EXPORTER`, and
`OTEL_LOGS_EXPORTER`. Setting `OTEL_METRICS_EXPORTER=prometheus` also starts a
scrape endpoint on port `9464`, separate from the application's own port.

For the full configuration surface — every variable, what each instrumentor
contributes, and how to configure telemetry in code — see
[docs/telemetry.md](https://github.com/epam/ai-dial-sdk/blob/development/docs/telemetry.md)
in the DIAL SDK repository.
