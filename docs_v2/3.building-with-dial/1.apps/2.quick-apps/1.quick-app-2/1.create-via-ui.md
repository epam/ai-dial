# Create a Quick App 2.0 in DIAL Chat

Quick App 2.0 is built through a visual wizard in DIAL Chat — no code, no config file. This page summarizes the wizard for developers and maps each step to the underlying configuration. For the field-by-field walkthrough with current screenshots, see [Build a Quick App](../../../../chat-user-guide-new/2.catalog/2.agents.md#build-a-quick-app) in the DIAL Chat User Guide.

To create a Quick App 2.0 programmatically, see [Create via API](2.create-via-api.md) or [Create via config.json](3.create-via-config.md).

## Prerequisites

- Access to DIAL Chat with an authenticated user account.
- At least one language model deployed in your DIAL instance.
- (Optional) MCP registered in DIAL Core if you want to add MCP tools.
