# What are Quick Apps

Quick Apps let you build an AI agent on DIAL without writing code. You pick a model, write its instructions, and connect the tools, skills, and files it needs; the model then decides which to use for each request. This page explains what a Quick App is, when to choose one, and the ways to create one. It is for app developers choosing how to build on DIAL, and assumes you know [the DIAL app types](../0.index.md).

## How a Quick App works

A Quick App has three parts:

- **A model** that reads the user's message, decides when to call tools, and writes the answer.
- **Instructions**, the system prompt that sets its purpose, tone, and scope.
- **Add-ons**: Toolsets, other agents, skills, files, and built-in tools such as a Python interpreter and web access.

The model works in a loop: it answers, or calls tools, reads their results, and continues until it can answer. Each tool call shows as a stage in DIAL Chat, so users see what the agent did.

A Quick App is a regular DIAL application. It is called through the Unified API like any other, shared and published like any other, and can itself be a tool of another Quick App. Behind it, the Quick Apps Backend runs every Quick App from its JSON manifest; see [DIAL Quick Apps](../../../6.services/8.quick-apps/0.index.md).

## When to choose a Quick App

A Quick App fits when:

- The task is something a capable model can do in one pass, given clear instructions and the right tools.
- You want to compose existing models, agents, APIs, and MCP servers, without code to write or host.
- You want to try an idea, test it, and change it in minutes.
- Users should be able to build their own agents.

For full control of the code and infrastructure, build a [Custom App](../4.custom-apps/0.index.md). For a Python app that DIAL hosts, build a [Code App](../3.code-apps/0.index.md). For a side-by-side comparison, see [When to use which](../1.when-to-use-which.md).

## Ways to create a Quick App

| Where | For | Guide |
|---|---|---|
| The Quick App editor in DIAL Chat | Anyone; the editor covers the common settings, and **Edit JSON** covers the rest | [Build a Quick App](../../../7.chat-user-guide/3.catalog/2.agents.md#build-a-quick-app), and the [tutorial](1.tutorial-build-an-agent.md) |
| The applications API | Developers automating app creation and updates | [Create a Quick App through the API](2.create-via-api.md) |
| The DIAL Core configuration | Administrators who provide Quick Apps to everyone | [Quick App applications](../../../6.services/8.quick-apps/3.configuration/3.dial-core-and-chat.md#quick-app-applications) |

All three produce the same manifest. Its fields are in the [Quick App manifest](../../../6.services/8.quick-apps/2.manifest/0.index.md), and complete manifests are in [Examples](../../../6.services/8.quick-apps/2.manifest/4.examples.md).

## Sharing and access

A new Quick App is visible only to you. You can share it with other people, or publish it to the Catalog through an approval. See [Sharing and publishing](../../../7.chat-user-guide/5.sharing-and-publishing.md).
