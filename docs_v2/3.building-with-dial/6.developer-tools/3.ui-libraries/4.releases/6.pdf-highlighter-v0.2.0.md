# DIAL PDF Highlighter 0.2.0

PDF Highlighter 0.2.0 adopts the UI Kit 0.14 tokens and the 2.0 design system, and reports page changes that the reader causes by scrolling. This page summarizes the release for frontend developers who plan an upgrade. There are no patch releases. DIAL Chat 1.2.22 pins this version.

## 0.2.0

Released 2026-09-14. [Release notes](https://github.com/epam/ai-dial-react-pdf-highlighter/releases/tag/0.2.0)

**Added**

- UI Kit 0.14 tokens and the 2.0 design system.

**Fixed**

- `onCurrentPageChange` reports page changes driven by scrolling.

**Other**

- The UI Kit is updated to 0.14.2 and `@epam/pdf-highlighter-kit` to 0.0.19.
- CI and dependency updates.
