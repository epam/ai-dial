# DIAL PDF Highlighter 0.3.0

PDF Highlighter 0.3.0 drops UI Kit 0.14, rebuilds its styles on Tailwind CSS v4, and aligns them with the DIAL Chat palette. This page summarizes the release for frontend developers who plan an upgrade. There are no patch releases.

## 0.3.0

Released 2026-11-04. [Release notes](https://github.com/epam/ai-dial-react-pdf-highlighter/releases/tag/0.3.0)

**Breaking**

- The `@epam/ai-dial-ui-kit` peer range is narrowed to `>=0.15.0-0 || >=0.16.0-0`, dropping 0.14.x. Upgrade the kit to 0.16.0, the version this release is built and tested against.
- The styles are rebuilt on Tailwind CSS v4 inside the `ui.*` cascade layers shared with the UI Kit. Unlayered host CSS now wins over the library's utilities, and `hover:` applies only on devices that can hover. Re-check host rules that target the library's elements.

**Added**

- The styles follow the DIAL Chat palette and shadow scale. `PDFViewer` is now transparent on the host surface; set a fill through `containerClassName` to keep the old raised background. `PageThumbnail` marks the selected page with an accent fill instead of a border.

**Fixed**

- Advisories in the development toolchain (`fast-uri`, `hono`, `@hono/node-server`, Storybook, and `npm audit` findings) are patched. They affect development only; the published `dist/` is unaffected.

**Other**

- Built and tested against `@epam/pdf-highlighter-kit` 0.0.20, whose viewer colors follow the DIAL theme through `--phk-*` variables, dark mode included. The peer range stays `>=0.0.19`.
- Storybook gains a light and dark theme toolbar with the DIAL Chat palettes.
