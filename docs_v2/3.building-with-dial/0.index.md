# Building with DIAL

This section is for developers who build applications, extensions, and integrations on the DIAL platform. Whether you are creating a no-code Quick App or writing a production-grade Custom App with the DIAL SDK, start here.

## Apps

The DIAL app ecosystem — Custom Apps, Quick Apps, and Code Apps. [Learn](1.apps/1.when-to-use-which.md) what each app type does, when to use it, and how it fits into the platform.

[Go to DIAL Apps](1.apps/0.index.md)

## Tools and enterprise data

- [Toolsets](2.toolsets/0.index.md) — connect an MCP server or expose a REST API as tools for an agent
- [Build a document Q&A app with Generic RAG](1.apps/5.generic-rag-document-qa.md) — create a knowledge base from documents indexed in advance

## Extension points

Interceptors that transform requests and responses in flight, and adapters that connect external AI providers to the Unified API.

- [Interceptors](3.interceptors/0.index.md) — middleware for PII redaction, content filtering, audit logging, and compliance enforcement
- [Adapters](4.adapters/0.index.md) — connect external AI providers to DIAL Core

## Developer tools

SDK reference, Chat customization, data visualization, theming, and the UI libraries.

- [SDK reference](5.developer-tools/1.sdk-reference/0.index.md) — Python framework for building Custom Apps and model adapters that plug into the DIAL platform
- [Chat customization](5.developer-tools/2.chat-customization/0.index.md) — developer-facing extension points and customization options that let you control what Chat renders, how it looks, and how it integrates with your applications
- [UI libraries](5.developer-tools/3.ui-libraries/0.index.md) — the React design system, file browser, and PDF viewer that the DIAL web interfaces are built from

## Integrations

[Integrations](6.integrations/0.index.md) connect DIAL with external systems — chatbots, productivity add-ins, workflow automation, and agentic tools.

- [Chatbot integrations](6.integrations/1.chatbot-integrations/0.index.md) — embed DIAL in Microsoft Teams and Microsoft Copilot
- [Productivity add-ins](6.integrations/2.productivity-add-ins/0.index.md) — bring DIAL's models and applications into the desktop and productivity tools your users already work in

- [Agentic tools](6.integrations/4.agentic-tools/0.index.md) — use DIAL as the model backend for coding agents and desktop assistants
