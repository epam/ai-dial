# Release Notes

The purpose of this document is to provide a quick summary of all the biggest new features added in this version and provide some additional description, video, or tutorials for major features.

## Brief Summary

The highlight of this release is **DIAL Chat 2.0**, a rebuilt chat experience that becomes the way forward for the platform — and makes this the final major release of the current chat application. Alongside it, **Agent Skills** are now supported end to end, from authoring in chat through governed publication in DIAL Admin, **Quick Apps** agents can draw on reference material from the systems they connect to, and **token accounting** across the platform becomes precise enough to bill and budget prompt caching accurately.

## Major Enhancements

**DIAL Chat 2.0**: In the 1.44 release notes we promised significant enhancements to the DIAL Chat UI as part of modernizing the DIAL user experience. This is that release. The chat your organization uses every day has been rebuilt on a new foundation, one designed to let the interface and its feature set evolve more freely than the current application allows. This is also the last major release of the current chat, which will continue to receive maintenance while organizations move across — the [upgrade guide](https://github.com/epam/ai-dial/blob/main/docs/releases/1.47/upgrade-to-1.47.md) covers the path in detail.

**Agent Skills, End to End**: Quick Apps gained support for Anthropic's Agent Skills format in 1.44, letting creators register structured instructions that extend what an agent knows how to do. This release completes the story. Skills are now available in DIAL Chat itself, so the people closest to a problem can build the capability they need where they already work. And DIAL Admin makes skills a first-class governed asset, with a dedicated Skills section and a Skill Publication approval queue: a skill authored by one team goes through the same review and publication path as a model, application or prompt before the wider organization can rely on it. As agent capabilities multiply across an enterprise, that combination — easy to create, deliberate to publish — is what keeps them useful rather than chaotic.

**Quick Apps: Agents That Read, Not Just Act**: Until now a connected tool could do something for an agent; this release lets it also give the agent something to read. Toolsets can expose their own reference material — documentation, catalogues, policies, whatever the connected system publishes — and the agent pulls in what it needs when it needs it, rather than having everything stuffed into its instructions up front. Creators choose what is offered and what loads immediately, so a large corpus stays available without inflating every request. Agents can also fetch public web content into their workspace to work with directly, currently available in preview mode.

Delegation gets more capable too. When an agent hands work to a sub-agent, that sub-agent can now keep its context across calls instead of starting cold each time, so multi-step work delegated across several specialists holds together the way a person would expect. And for multinational organizations, tool names and descriptions can be localized and are shown to each user in their own language automatically, with the editor guiding creators through it.

**Token Accounting You Can Bill Against**: Prompt caching cuts the cost of repeated context dramatically, but only if the savings are visible. DIAL Core now prices cached reads and writes separately from fresh tokens, tracks reasoning and cache-write tokens in usage statistics, and reports the result through the same reporting surfaces organizations already use for chargeback. The adapters do their part too: token counts now come from the model provider itself rather than being estimated locally, which matters for organizations enforcing per-user or per-team limits where an estimate is not good enough. Teams running large recurring workloads should expect both a lower bill and a clearer explanation of it.

## Additional Notes

For full technical release notes with all bug fixes and additional features, please consult the [upgrade guide](https://github.com/epam/ai-dial/blob/main/docs/releases/1.47/upgrade-to-1.47.md) with all the tags for each component, as well as the [DIAL documentation](https://docs.dialx.ai).

- **Bedrock Adapter**: Support for Claude Opus 5, Sonnet 5 and Fable 5, and the MiniMax M2.5 model
- **OpenAI Adapter**: Anthropic passthrough now supports the Claude Platform and third-party Anthropic API providers
- **Catalog Metadata**: Models, applications and toolsets can now carry catalog metadata, giving the Marketplace richer and more consistent information about every entity
- **OpenAPI to MCP**: A new component generates agent tools directly from an existing API specification, so an internal service can be made available to agents without commissioning a custom integration
- **Conversation Analytics [Preview]**: A new Conversations view in DIAL Admin shows what actually happened in a conversation, down to the individual turn
- **Evaluation**: Test cases can now carry a sequence of turns, so multi-step agent behaviour is evaluated the way it is actually used
